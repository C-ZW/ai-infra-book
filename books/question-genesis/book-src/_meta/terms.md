# 規範術語集（Canonical Terms）

## 術語維護原則

1. **單一源頭定義**：每個術語在「首次定義章節」進行最完整、具備現場故事張力與具體推演的展開。
2. **跨章引用紀律**：後續章節使用該術語時，一律以 `（見 chNN）` 指向該源頭章節，嚴禁在後續章節另闢段落重新推導或複製定義。
3. **語意純淨**：全書一律採用繁體中文（zh-TW）規範名詞，不使用簡體或大陸用語（資訊不用「信息」、機率不用「概率」、預設不用「默認」、演算法不用「算法」）。數學關係一律使用純 Unicode 符號，不混入 LaTeX 標記。
