# 史實與數據基準：第 22 章 巴斯德的鏡像晶體（ch22）

- **人物與時間**：路易·巴斯德（Louis Pasteur, 1822–1895），法國化學家與微生物學奠基者。1848 年於巴黎高等師範學院（École Normale Supérieure）完成酒石酸研究。
- **刺眼的化學謎團**：
  - 釀酒桶沉澱提取的**天然酒石酸**（tartaric acid）：具有旋光性，能使偏振光偏轉。
  - 人工合成的**副酒石酸（外消旋酒石酸，paratartaric / racemic acid）**：化學組成、分子量、熔點與密度完全相同，但對偏振光完全呈光學惰性（不偏轉）。著名物理學家畢奧（Jean-Baptiste Biot）與德國化學家三井徹立希（Mitscherlich）對此困惑不解。
- **關鍵實驗操作（B20）**：
  - 巴斯德配製酒石酸鈉銨與副酒石酸鈉銨溶液，在低於 26–28 °C 的低溫條件下緩慢結晶。
  - 在顯微鏡下觀察到副酒石酸晶體並非單一形態，而是由兩種呈互為鏡像的「不對稱半面晶形（hemihedral facets）」所構成。
  - 巴斯德用鑷子一顆一顆手動挑選，將「左手晶體」與「右手晶體」分成兩堆。
  - 將兩堆晶體分別重新溶解：右手晶體溶液向右旋轉偏振光，左手晶體溶液向左旋轉偏振光；以 1:1 混合後，旋光性剛好完全抵消！
- **劃時代意義**：首次證明宏觀晶體的幾何不對稱性來源於微觀分子的三維空間手性（chirality），奠定了現代立體化學（stereochemistry）的基石。
