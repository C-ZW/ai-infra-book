# 史實與數據基準：第 23 章 休伯爾與威澤爾的玻片邊緣（ch23）

- **人物與時間**：大衛·休伯爾（David H. Hubel, 1926–2013）與托斯登·威澤爾（Torsten N. Wiesel, 1924–），約翰霍普金斯大學威爾默眼科研究所（Wilmer Eye Institute），1958–1959 年實驗。
- **背景與死結**：
  - 哈特蘭（K. Keffer Hartline）與庫夫勒（Stephen Kuffler）發現視網膜神經節細胞具有「同心圓同心環拮抗感受野（center-surround receptive fields）」。
  - 神經科學界普遍預設大腦初級視覺皮層（V1）也運作著相同的圓形光點解碼機制。休伯爾與威澤爾用圓形光點刺激貓眼數小時，微電極記錄到的皮層神經元幾乎毫無反應。
- **意外突破（B21）**：
  - 1958 年底某次實驗中，在眼底鏡投影儀中抽換載玻片時，微電極音頻揚聲器突然爆發出劇烈的「劈啪劈啪」放電聲。
  - 排查確認：誘發神經元劇烈放電的不是任何圓形光斑，而是**透明載玻片的筆直邊緣**在螢幕上投下的一道極微弱的直線陰影！
- **劃時代發現**：
  - 初級視覺皮層神經元不是點探測器，而是**方向選擇性特徵探測器（orientation selectivity）**。
  - 發現簡單細胞（simple cells）與複雜細胞（complex cells）的分層階層式視覺特徵建構（從點、到線段、到輪廓、到物體形貌）。
  - 發現皮層功能柱（orientation columns）與眼優勢柱（ocular dominance columns），開啟現代神經科學與卷積神經網路（CNN）的架構源頭。榮獲 1981 年諾貝爾生理學或醫學獎。
