# 寫作風格指南（內部文件，非書籍內容）

本文件是《問題誕生之前：從理所當然到值得追問》的寫作契約。每一章都必須遵守，否則全書會失去一致性。

## 這本書是什麼、不是什麼

- **是**：一本給對世界好奇的一般讀者的「問題誕生學」深讀作品（form = `narrative`，reader register = `general`）。透過歷史上科學家、哲學家、數學家、發明家的真實探索歷程，帶讀者走進「解答出現之前」的那段幽暗時刻：
  1. **當時的人（包含探索者自己）原本把什麼視為理所當然？**
  2. **哪一個格格不入的微小細節、殘差或矛盾引起了注意？**
  3. **最初模糊、說不上來的困惑，如何經過拆解、轉換尺度或翻轉前提，逐漸收斂成一個「值得追問、可以回答」的真問題？**
- **不是**：
  - 不是科學史流水帳或偉人傳記合輯——不寫生平大事紀，不造神，不灌雞湯，不喊「只要堅持就能成功」；歷史場景唯一的作用，是讓讀者親身經歷「問題在眼前卻還看不見」的認知張力。
  - 不是「提問技巧速成手冊」——不列空洞的口號公式、不用六段固定教條模板；本書希望讀者跟著故事自己慢慢領悟，在讀完每一章時，不知不覺學會一種觀看日常的新眼光。
  - 不是某個行業的內部筆記——**全書面向一般受過基礎教育、對世界好奇的讀者，不假設任何專業背景，絕不寫入任何個人履歷、公司或工程師行話**。當需要連結到讀者的日常經驗時，一律使用每個人都經歷過的普遍生活場景（搭車、看地圖、廚房、看診、修理家電、看氣象預報）。

## 脊椎（貫穿全書的單一主線）

**每一個改變世界的答案，都始於有人對一句「本來就這樣」起了疑心，並把一團模糊的困惑鍛造成一把精準的問號。**

這條脊椎在全書每一章都以「**問題顯影四階**（The Four Stages of Question Genesis）」作為內在敘事弧線（融入連續散文敘事中，不作為生硬的填空表格）：
1. **背景噪音**（The Taken-for-Granted）：當時所有人覺得天經地義、甚至不覺得那裡有問題的「透明前提」。
2. **刺眼裂縫**（The Snag / Anomaly）：一個怎麼抹都抹不掉的怪異細節——一個多出來的數字、一群「應該生病卻沒生病」的人、一條不肯下降的曲線、兩句合在一起會打架的常識。
3. **困惑對焦**（From Fog to Focus）：探索者最初怎麼問錯問題、撞上死胡同，最後如何換一個動詞、換一把尺、或切掉多餘的雜訊，把「怎麼會這樣？」變成「如果 A 成立，B 應該是多少？」。
4. **日常顯影**（The Everyday Lens）：章末不寫「課後測驗」，而是留給讀者一個生活中的微觀觀察鏡頭——當你走出這一章，今天在街上、廚房或新聞裡，哪一句「本來就這樣」值得你多看兩眼？

## 讀者校準（Reader Profile & Register）

- **目標讀者**：對世界充滿好奇、喜歡思考、但不一定具備理工或哲學專業背景的一般讀者（Reader register: `general`）。
- **預設已具備**（Assume-known）：日常生活常識、國中至高中基礎算術與幾何直覺（比例、速度＝距離÷時間、平均數、三角形內角和 180°、簡單的面積與距離概念）。
- **當場用白話與直覺帶出**（Teach-in-context）：凡是故事中涉及的科學或數學概念（如游離、光譜暗線、角動量與引力平衡、資訊熵、分數維度、非歐幾何公設），一律用故事現場的具體事物與數字一步步算給讀者看，不甩專業術語，不假設讀者背過公式。
- **個人材料規則**：遵守 `zh-prose.md`，不引用任何個人履歷、職涯或特定技術系統。

## 章節排序原則（Chapter-Arc Principle）

全書 12 章按「**問題生成的四種深層機制**（難度由淺入深、從感官走向抽象）」排列：
- **Part I｜撬開「本來就這樣」**（ch01–ch03）：問題被「太熟悉的常識」擋住。探索者必須先讓熟悉的事物變陌生（伽利略的落體與思想實驗、斯諾地圖上「沒生病的人」與艾克曼吃白米生病的爪哇雞群）。
- **Part II｜聽見「不對勁的雜訊」**（ch04–ch06）：問題藏在「跟預期差一點點」的殘差裡。多數人把誤差掃進地毯下，探索者卻緊咬那個微小的不合（萊特兄弟少掉三分之二的升力、塞西莉亞·佩恩被權威斥為荒謬的太陽氫譜線、彭齊亞斯與威爾遜除不掉的 3.5 K 雜訊）。
- **Part III｜看穿「沉默的預設」**（ch07–ch09）：問題卡在「所有人共用的隱形框架」。要問出真問題，必須先看見自己站在什麼假設上（薇拉·魯賓不肯慢下來的星系邊緣、麥克林托克玉米粒上的跳躍基因、博伊亞伊與羅巴切夫斯基放棄證明第五公設）。
- **Part IV｜重鑄「問題的形狀」**（ch10–ch12）：最高階的提問——原本的問題根本問錯了。探索者透過換一把尺、剝離無關維度，把一團哲學迷霧變成可計算的新世界（曼德博的英國海岸線、圖靈與夏農如何把「計算」與「訊息」拆成動作與位元、以及 ch12 收官：在日常生活中培養「問題感」的完整地圖）。

## Form Contract — Narrative（深讀散文體契約）

1. **一章一核心主題，連續散文推進**：
   - **禁止使用 `instructional` 的六段固定標題骨架**（不得出現 `## 從你已知的出發`、`## 直覺的陷阱`、`## 紙上推演`、`## 自我檢核`、`## 延伸閱讀` 等教科書欄位）。
   - 每章內部的小節標題（`##`）必須跟隨該章的人物故事與推理轉折量身命名，服務於敘事張力。
2. **零灌水**（Zero Filler）：
   - 每一段文字都必須推進故事或深化「問題如何成形」的洞察。禁止「本章我們將介紹…」「總結來說，以上我們看到了…」這類空洞過渡段。
3. **跨章概念與交叉引用**（Mandatory Cross-references）：
   - 每個核心方法論概念（如「思想實驗的內部矛盾法」「負面證據／缺席的異常」「殘差不丟棄原則」「公設翻轉」「尺度依賴」）在首次登場的章節完整定義與展開；後續章節再次觸及時，以「（見 chNN）」自然回扣，不重複定義。
4. **深度與具體算例**（Depth & Concrete Walkthrough）：
   - 雖然是面對大眾的敘事體，**絕不犧牲具體性**。每章必須維持充足深度（5,000–8,000 中文字），並包含**至少一個放在 ` ```text ` 圍欄區塊內的具體數字／邏輯推演對照框**（例如：伽利略綁石頭的速度矛盾推演、倫敦寬街霍亂未發病者與爪哇監獄白米對糙米的發病率對照表、萊特兄弟斯米頓係數的升力落差試算、海岸線隨尺規縮小的長度倍增表），讓一般讀者親眼看見「模糊困惑如何變成精確問題」。
   - ASCII 圖表或資訊框必須遵守 CJK=2 欄寬對齊規則，並通過 `check_diagrams.py`。
5. **史實與數字鐵律**：
   - 所有歷史年份、數據、人物引述與傳說標註，嚴格對齊 `_meta/landscape-2026-10.md` 與 `outline.md` 的基準數字表。傳說（如比薩斜塔丟球、比薩教堂吊燈）必須誠實點明是傳記作者記載的傳說，並說明為何「真實的思維過程比傳說更精彩」。

## zh-TW 措辭契約（白話直述，動詞優先）

寫給人讀的繁體中文（台灣慣用語），不是譯稿。判斷標準：一句話唸出聲，像不像一個博學而誠懇的朋友在跟你講故事。

### 禁止簡體字與中國大陸慣用語
- 機率（不用「概率」）、資訊（不用「信息」）、預設（不用「默認」）、演算法（不用「算法」）、品質（不用「質量」指好壞）、常態（不用「正態」）、變異（不用「方差」）、網路（不用「網絡」）、透過／藉由（不用「通過…來」表手段）。

### 禁止的翻譯腔模式（lint 以 WARN 偵測）

| 模式 | 改法 | 例 |
|---|---|---|
| 「進行／加以」＋動作名詞 | 直接用動詞 | 進行觀察 → 觀察；進行分析 → 分析 |
| 「透過…的方式」 | 用／靠／以 | 透過測量的方式發現 → 測量後發現 |
| 「在…的情況下」 | 當／若／…時 | 在沒有望遠鏡的情況下 → 沒有望遠鏡時 |
| 「對於…而言」 | 對… | 對於當時的醫生而言 → 對當時的醫生來說 |
| 「存在著」 | 有 | 存在著一個矛盾 → 有一個矛盾 |
| 「是…的」空殼斷言連用 | 拆掉空殼 | 這是不可能的 → 這不可能 |
| 「作為（一個）…」開頭 | 換主語直述 | 作為一個年輕學者，他… → 年輕的他… |

### 節奏與句構
- 一段一個核心畫面或論點；綿密的歷史細節描寫之後，用一個乾淨有力的短句收束。
- 名詞化堆疊（「…的…的…的」三連以上）一律拆開重寫。
- 被動語態「被」只在受事者是焦點時使用；平常一律用主動語態。
