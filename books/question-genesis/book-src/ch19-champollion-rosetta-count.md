# 第 19 章 羅塞塔石碑上的字數違和感：當象形文字不只是圖畫

當你走進一座古老的神廟，抬頭仰望石壁，看見一隻展翅的獵鷹、一隻警覺的貓頭鷹、一條盤蜷昂首的眼鏡蛇，以及一個雙手高舉跪地的男子，你的大腦會立刻做出什麼反應？

你的視覺皮質會在瞬間辨識出這些具體的形象。你不會覺得這是一串抽象的音節，你會本能地認為：這是一幅畫，畫著大自然裡的生靈與姿態。如果你被告知這些圖案是古代祭司留下的神聖文字，你更會順理成章地猜測：獵鷹大概象徵著神聖的王權或迅捷的敏銳，貓頭鷹代表夜間的守護或死亡的沉靜，盤蛇象徵致命的威嚴，而那個跪著的人則象徵對神祇的虔誠祈禱。

這是一種極難抵抗的直覺。因為眼睛看見的是「物」，心靈便自然而然把符號當成了「物」的直接倒影。

在長達一千四百年的歲月裡，正是這種看似天經地義的直覺，把全歐洲最博學的學者們牢牢困在了一場壯麗的集體催眠之中。所有人都在絞盡腦汁猜測每一隻鳥、每一條蛇到底蘊含著多麼深奧的宇宙密碼，卻沒有一個人停下腳步，去數一數石碑上到底刻了多少隻鳥、多少條蛇。

歡迎來到本書的第七部：**拆穿「名字與符號的催眠」**。

回看我們走過的二十四章探索地圖：
在第一部，我們學會了撬開「本來就這樣」，看伽利略用紙上的兩塊石頭擊碎落體常識（見 ch02），斯諾從疫區地圖上缺席的生病者看穿霍亂真相（見 ch03）；
在第二部，我們學會了聽見「不對勁的雜訊」，看萊特兄弟在風洞裡緊咬抄了一百五十年的氣壓常數（見 ch04），佩恩從被視為儀器誤差的暗線訊號看見太陽的真實氫含量（見 ch05），彭齊亞斯與威爾遜揪出除不掉的 3.5 度宇宙餘溫（見 ch06）；
在第三部，我們學會了看穿「沉默的預設」，看魯賓在星系邊緣看見不肯減速的恆星（見 ch07），麥克林托克在玉米田裡推翻基因固定論（見 ch08），博伊亞伊看穿平行公設不必為真（見 ch09）；
在第四部，我們學會了重鑄「問題的形狀」，看曼德博用不同尺規量出不斷膨脹的海岸線（見 ch10），圖靈與夏農把計算與訊息徹底從具體語意中剝離（見 ch11），並在第十二章整理出日常提問的十二把透鏡；
在第五部，我們學會了識破「假裝代表全體的樣本」，看瓦爾德在返航轟炸機上尋找沒能飛回來的死難分母（見 ch13），丹尼爾斯在四千名飛行員裡找不到一個平均身材（見 ch14），皮亞傑在巴黎錯題本裡發現兒童心智的運作結構（見 ch15）；
在第六部，我們學會了換掉「被卡死的時間鏡頭」，看阿加西在巨石擦痕中看見極慢流動的固態冰河（見 ch16），阿爾瓦雷茨在一公分黏土中量出瞬間撞擊的銥異常（見 ch17），馬歇爾與華倫在復活節五天長假中孵出幽門螺旋桿菌（見 ch18）。

現在，我們抵達了第七部。我們將面對人類思維最難察覺的一道隱形牢籠——**名字與符號的催眠**。

人類發明符號、語言、分類表與體制規則，原本是為了在混亂無序的宇宙中標記秩序。然而，一旦一個名字被叫順了口、一個圖形被奉為神聖、一張表格被蓋上了權威的印戳，我們的心智往往會反過來被符號綁架。我們習慣看著罐子上的標籤爭論不休，卻忘記拉開抽屜，看看罐子裡的實物到底長什麼模樣。

## 赫拉波羅的一千四百年咒語：神聖的圖畫不可能發音

公元三九四年八月二十四日，在尼羅河菲萊島（Philae）的伊西斯神廟石壁上，一位名叫埃斯梅特-阿科姆（Esmet-Akhom）的祭司，刻下了人類歷史上最後一行已知的古埃及象形文字。

當時，羅馬帝國皇帝狄奧多西一世已頒布敕令關閉帝國境內所有非基督教神廟。隨著最後一批祭司衰老逝去，古埃及象形文字徹底退出了人類的歷史舞臺。尼羅河畔居民改宗基督教，改用以希臘字母為骨架的科普特字母記錄日常口語；古老的聖書體石刻，在黃沙中化為無人能解的天書。

然而，文字雖已失傳，「對文字的想像」卻化為一套不可撼動的神秘哲學。

大約在公元五世紀，自稱埃及祭司後裔的學者赫拉波羅（Horapollo），撰寫了名為《象形文字之謎》（*Hieroglyphica*）的著作。這部小書宣稱記錄了象形文字的真正內涵。赫拉波羅告訴讀者：古埃及的每一個象形符號，都不是用來拼讀凡俗聲音的字母，而是深奧神聖的**表意符號**（ideograms）。

在赫拉波羅筆下，每一幅圖畫都是宇宙哲理的微縮模型：
為什麼禿鷹代表「母親」？赫拉波羅解釋，因為禿鷹全靠迎著南風受精繁衍，是純粹母性與自性繁衍的聖潔象徵；
為什麼野鵝代表「兒子」？因為野鵝遭遇獵人襲擊時，會主動撲向陷阱犧牲自己，保護雛鳥逃生；
為什麼蜜蜂代表「君王」？因為蜜蜂社會嚴守階級，工蜂對蜂后絕對服從；
為什麼糞金龜代表「獨一無二的造物」？因為聖甲蟲在泥中推動圓球，象徵太陽神自我孕育、推動天體運行的造化偉力。

一四一九年，這部手稿在希臘被發現並傳回佛羅倫斯，文藝復興學者如獲至寶。歐洲知識界深信「原初神學」（*prisca theologia*）：在巴別塔導致人類語言墮落為凡俗拼音之前，古埃及賢者掌握著直通神明心靈的思維——思想無需經過肉體聲帶震動，單憑圖像便能直接在靈魂之間激發共鳴。

到了十七世紀，羅馬耶穌會全才柯雪（Athanasius Kircher）在巨著《埃及的伊底帕斯》（*Oedipus Aegyptiacus*）中，更將這套表意神話推向極致。面對方尖碑上僅由幾個常見符號組成的簡短王名圈——我們今天清楚知道那不過是法老阿普里斯或羅馬皇帝圖密善的名字——柯雪卻能用拉丁文寫出整整三頁的玄思：「萬物繁育之源乃是奧西里斯，其神聖創造之力藉由聖靈莫夫塔自天界導入其國度，經由尼羅河之生機化育萬靈……」

柯雪的權威讓全歐學界深信不疑：**象形文字是絕對不可拼讀的純神聖圖畫**。凡是試圖在裡面尋找子音母音的人，都被視為對古代智慧的褻瀆。這道神聖咒語，一施就是一千四百年。

一七九九年七月十五日，拿破崙遠征軍在埃及羅塞塔（拉希德，Rashid）修建朱利安要塞時，工程軍官布夏賀（Pierre-François Bouchard）在拆毀舊牆時挖出了一塊重達七百多公斤的花崗閃長岩石碑。拿破崙隨軍的一百六十七位科學家與學者立刻意識到這塊石碑的非凡價值，迅速墨拓石碑銘文並分送歐洲各大首都。

這便是震撼文明史的「羅塞塔石碑」（Rosetta Stone）。

石碑記錄著同一篇由孟菲斯祭司團於公元前一九六年發布的托勒密五世登基詔書，由三種字體並列刻成：
最上方是殘缺不全的**聖書體象形文字**（Hieroglyphs），獻給神祇與祭司；
中間是筆勢流暢的**世俗體草書**（Demotic），供埃及百姓日常行政往來；
最下方是保存相對完整的**古希臘文**（Ancient Greek），為統治宮廷的官方語言。

底部的希臘文人人能讀，這等於送給人類一把一字不差的對照鑰匙。然而二十多年過去，這把鑰匙插在鎖孔裡卻完全轉不動。

連英國頂尖物理天才托馬斯·楊（Thomas Young）——光的雙狹縫干涉實驗與楊氏模數提出者——也僅僅跨出了一小步。楊比對世俗體與希臘文，認出繩圈圍起的橢圓王名圈（cartouche）內刻著國王「托勒密」（Ptolemaios），並成功對應出 P、T、O、L、M 等幾個發音字母。

隨後在一八二一年，英國探險家班克斯（William John Bankes）將菲萊島方尖碑運回英格蘭。這座方尖碑基座刻著希臘文，碑身刻著象形文字，銘刻著另一位著名統治者「克麗奧佩脫拉」（Cleopatra，埃及艷后）的名字。當托勒密與克麗奧佩脫拉的王名圈並列在桌上時，鐵證如山：代表字母 P 的方塊、代表字母 L 的蹲伏獅子、代表字母 T 的半圓形，精準無誤地出現在兩個名字的對應位置上！

任何一個清醒的人看到這裡，都該意識到古埃及文字具備字母拼音體系。

然而，楊隨即被赫拉波羅的千年咒語拉回深淵。楊在《大英百科全書》附錄中斷言：古埃及文字本質上毫無疑問是純表意符號；唯有書寫「外族統治者」名字時，祭司才被迫借用符號聲音勉強拼音，就像用獸鳴拼寫野蠻人的外語。

「外族名字例外論」成了舊典範最頑固的防空洞：除了外國國王名字，石碑其餘正文依然被認定是百分之百的純表意圖畫。學者們心滿意足地縮回防空洞，破解大門再次緊閉。

## 斷裂石碑上的小學算術：四百八十六對一千四百一十九

打破這場千年催眠的，是法國語言學怪才讓-弗朗索瓦·商博良（Jean-François Champollion, 1790–1832）。

商博良出身菲雅克貧寒之家，十歲自學希伯來文，十二歲精通希臘文與拉丁文，但他將全副心力傾注在科普特語上。

科普特語是古埃及語演變出的最後型態，埃及基督徒用希臘字母加上七個世俗體字母記錄母語。雖然象形文字寫法失傳，古埃及語的語音與詞彙卻完好冰封在科普特語聖詩與日常禱文裡。商博良給兄長寫道：「我要像了解法語一樣了解埃及語，我甚至自言自語都在用科普特語思考。」

但光懂口語還不夠；只要石刻仍被當成不可發音的圖畫，聲音與圖像就無法連結。

真正讓商博良擊碎千年成見的，不是神秘靈感，而是一次樸實得近乎笨拙的小學算術（B17）。

一八二一年底，商博良在巴黎那間狹小的閣樓書桌上攤開羅塞塔石碑拓本。二十年來，所有人都在用放大鏡審視鳥獸爪足的繪畫細節；商博良卻拿起羽毛筆，做了前人從未做過的事：**清點石碑上的字數。**

這是一場極其冷酷的客觀丈量：

最底部的古希臘文保存相對完好，共五十四行。整篇法令敘事嚴密，商博良逐詞清點，得出確鑿基準：
**古希臘文正文共有 486 個單詞**。

接著看最上方的象形文字區塊。
只要看一眼石碑的人都會發現，象形文字的保存狀況極其慘烈：頂部弧邊與兩側上角盡皆崩毀，僅剩最後十四行殘斷文字。金石學家普遍推估，**殘存篇幅不足整篇法令的三分之一**！

按照全歐洲深信了一千四百年的「一圖代表一詞、一概念」的純表意假說，既然希臘全文用了 486 詞，不到三分之一篇幅的象形殘卷，至多應只有一百多個符號。

然而，當商博良沿著殘存十四行斷片，將石壁上的鳥、蛇、水波與方塊從頭到尾數過一遍後，跳出的數字令人震驚：

殘存象形文字符號總數，高達整整 **1,419 個個別象形符號**！

商博良拿出一張白紙，將這 1,419 個符號逐一分類歸納，相同圖案歸為同類。第二個更加詭異的數字隨即浮現：

在足足 1,419 個反覆出現的符號陣列中，獨立的基本圖案種類，竟然只有 **166 種**！

商博良的兄長雅克-約瑟夫曾驚訝地看著弟弟在紙上劃下一排排計數的正字標記。在古典金石學界，從來沒有一位學者會把神聖文字當作工廠庫存一樣逐一清點。然而，正是這種不帶神祕色彩的客觀計數，讓羅塞塔石碑赤裸裸地暴露出它的資訊極限。

請凝視這三個並排在桌上的數字：
**希臘文完整單詞：486 個**
**殘缺象形文字符號：1,419 個**
**象形文字獨特種類：166 種**

這三個數字引爆了純表意假說的內部瓦解：

**第一道矛盾：數量的荒謬膨脹。**
若一符號代表一詞（1:1 純表意），殘缺三分之一的篇幅怎會含有 1,419 個單詞？若將破損石碑補齊，整篇象形文字將擁有四千多個詞！對等的官方政治法令，埃及文怎可能比精練的希臘文冗長近十倍？

**第二道矛盾：詞庫的致命貧乏。**
若一符號代表一詞，意味著整篇涉及免稅、兵力布署、灌溉糧賦、祭儀神龕的國家大法，全篇翻來覆去只用了 166 個詞彙！人類怎可能用 166 個單詞起草一份涵蓋賦稅、宗教與軍事的完整國家法典？哪怕是幼童的日常對話，詞彙量也遠超 166 個詞！

這兩道矛盾如鐵鉗般將舊假說徹底夾碎：

```text
┌────────────────────┬────────────────────────────┬──────────────────────────────────┐
│ 比較維度           │ 古希臘文銘文（基準）       │ 殘缺象形文（受損頂層）           │
├────────────────────┼────────────────────────────┼──────────────────────────────────┤
│ 1. 碑文保存狀況    │ 底層完好，完整詔書全文     │ 頂部及邊緣崩毀，殘存不足 1/3     │
│ 2. 表面文字總數    │ 486 個希臘單詞             │ 足足 1,419 個個別象形符號        │
│ 3. 獨特符號種類    │ 24 個希臘字母（拼音系統）  │ 僅 166 種不同圖案（反覆組合）    │
│ 4. 純表意假說預期  │ 1 詞表達 1 個獨立概念      │ 若 1 圖 = 1 詞，殘卷應 < 160 詞  │
│ 5. 刺眼的數量矛盾  │ 486 詞足夠表達完整政令     │ 殘卷符號數竟達希臘文近 3 倍！    │
│ 6. 詞彙庫容量矛盾  │ 語意豐富，表達複雜律令     │ 區區 166 種圖案無法寫出整部法令  │
│ 7. 資訊容量推論    │ 字母拼讀，字詞容量無限     │ 符號必然用來拼音（複合表音體系） │
└────────────────────┴────────────────────────────┴──────────────────────────────────┘
```

這組顯著的算術反差，強烈動搖了傳統純表意假說的前提：
**那些刻在石頭上的鳥、蛇、眼睛與方塊，絕非純粹獨立單詞，而是包含表音符號、表意符號與限定符（determinatives）的精密複合體系！**
正如商博良日後在劃時代著作《致達西耶先生的信》（*Lettre à M. Dacier*, 1822）與《埃及象形文字體系要綱》（1824）中所總結的至理名言：「這是一套複雜的體系，在同一篇文章、同一個句子，甚至同一個詞彙中，同時具備具象性、象徵性與表音性。」因為有大量符號用作拼音，串聯拼寫一個詞需要數個符號，總量才會膨脹至 1,419 個；也正因是拼音、表意與限定符的複合，區區 166 種基本圖案便能精確拼寫出成千上萬詞彙。象形文字不是神祕圖畫，而是一套精準嚴密的複合語言文字系統。

## 剝除語意看容量：從商博良到夏農的通道思維

商博良在此展現的思維躍遷，與一百二十六年後夏農創立現代資訊理論時（見 ch11），在方法論上展現了驚人的一致。

在第十一章我們看到，夏農冷酷地把訊息的「具體語意」徹底剝離，只問一個底層問題：信道每秒能傳遞多少個無語意的二進位自由度？商博良面對石碑時也是如此：他不再揣摩獵鷹蘊含何種宇宙哲理，而是將獵鷹當成符號 A、蛇當成符號 B，追問符號通道的資訊容量與自由度。

這也呼應了第十章曼德博重鑄問題尺度的眼光（見 ch10）：當你站在繪畫尺度看石碑，你看到的是無盡的象徵譬喻；但切換到符號組合數學，系統本質便無所遁形。

任何承載自然語言的文字系統，在數學上都面臨嚴苛邊界：
純表意文字（如漢字）需數千至數萬符號；
純音素文字（如希臘文、拉丁文）僅需二十至三十字母；
純音節文字（如日語假名）需五十至一百符號。

商博良算出的 166 種，恰好落在表音與音節的交界。這組關鍵的算術落差，像一記重錘砸碎了純表意神話，成為他破譯征途上的決定性線索。然而，光有字數統計並不能自動拼出整套語言——商博良隨後將這項算術突破，與他深厚的古埃及後裔語言（科普特語）知識、托馬斯·楊對托勒密王名圈的初步辨識，以及雙語方尖碑上克麗奧佩脫拉名字的字母交叉驗證緊密結合在一起！

問題不再是「圖畫傳播何種神祕哲學」，而是「這些符號在科普特語的語音與字彙體系中如何被發音與解讀？」。

## 阿布辛貝的信封：拉美西斯、圖特摩斯與五天昏厥

然而，學術界的偏見永遠比理性頑固。

反對派立刻搬出托馬斯·楊的最後防線：托勒密王朝是希臘人，借音符號只是拼寫外國名字的特例。商博良必須找到本土遠古法老王名圈作為鐵證。

一八二二年九月十四日早晨，法國建築師於約（Jean-Nicolas Huyot）寄來了他在尼羅河上游深處阿布辛貝（Abu Simbel）神廟臨摹的王名圈拓圖。阿布辛貝直接開鑿於努比亞懸崖絕壁，建於埃及新王國十九王朝全盛期，早於希臘征服一千多年，絕無外族痕跡。

商博良展開拓圖，目光死死鎖定一個橢圓王名圈：

最頂端是圓盤太陽，科普特語「太陽」發音為 **Ra**（ⲣⲏ）；
太陽下方是三叉枝枒狀符號，在羅塞塔雙語段落中對應「誕生」，科普特語發音為 **mes**（ⲙⲓⲥⲉ）；
下方並排兩張折疊布，商博良已驗證其發音為輔音 **s**，兩張布即 **s-s**。

拼讀發音：
**Ra — mes — su**。

**拉美西斯（Ramses）！**
阿布辛貝神廟建造者、古代埃及歷史上最顯赫的本土法老拉美西斯二世！

商博良抓起另一張古老拓圖：
頂端是長喙朱䴉，智慧之神托特（Thoth，科普特語 Ⲑⲱⲟⲩⲧ）聖獸；
下方同樣是三叉誕生符號 **mes** 與折疊布 **s**。

拼讀發音：
**Thoth — mes**。

**圖特摩斯（Thutmose）！**
第十八王朝威名遠播、開拓埃及帝國最遼闊疆域的本土傳奇法老！

這揭示出古埃及象形文字最驚人的雙重特質：同一個太陽符號，既可當作表意圖案（指代天上的太陽），更可充當表音文字（指代音節 Ra）！三千三百年前本土法老的名字，自始至終都是用聲音拼寫出來的！「外族例外論」徹底坍塌，象形文字自始至終都是表音體系！

三十一歲的商博良再也無法克制情感，抓起手稿衝入巴黎街頭狂奔。他跑過塞納河上的橋樑，衝進法蘭西文學院大樓，踢開兄長辦公室大門，用盡全力嘶吼出：

「**我抓到它了**！」（*Je tiens mon affaire !*）

隨即眼前一黑，重重癱倒在冰冷木地板上。長年營養不良、嚴重貧血與連續數十個晝夜的神經緊繃擊垮了他，商博良高燒昏迷整整五天。

九月二十七日，他抱病宣讀劃時代的〈致達西耶先生信〉（*Lettre à M. Dacier*），台下坐著渡海而來的托馬斯·楊。象形文字被正式宣告為表音表意兼具的精密體系，沉睡千年的古埃及文明重獲聲音。

## 問題顯影四階：符號外衣下的算術反差

```text
┌──────────────────────────────────────────────────────────────────────────┐
│                       象形文字破解的問題顯影四階                         │
│                                                                          │
│   1. 背景噪音 ───► 2. 刺眼裂縫 ───► 3. 困惑對焦 ───► 4. 日常顯影         │
│    （純表意神話）   （字數容量倒掛） （本土王名拼讀） （穿透符號催眠）   │
└──────────────────────────────────────────────────────────────────────────┘
```

1. **背景噪音（The Taken-for-Granted）**：
   眼睛看見具象鳥獸，便認定「符號即概念」。自五世紀赫拉波羅《象形文字之謎》以降，全歐深信古埃及文字是純神聖表意圖畫；托馬斯·楊雖識得王名拼音，卻退縮於「外族借音特例論」。
2. **刺眼裂縫（The Snag / Anomaly）**：
   一組無人理會的算術反差（B17）：完好希臘文僅 486 詞，殘缺三分之一的象形文竟有 1,419 個符號，且僅由 166 種圖案構成。這項強烈的數量矛盾成為動搖 1:1 純表意神話的關鍵線索。
3. **困惑對焦（From Fog to Focus）**：
   問題從「圖畫象徵何種哲理」重鑄為資訊容量問題：「何種系統用 166 種零件組合出 1,419 個標記以表達不到五百個概念？」。推演出複合拼音架構，並由阿布辛貝本土法老（拉美西斯、圖特摩斯）王名拼讀徹底證實。
4. **日常顯影（The Everyday Lens）**：
   穿透現代職稱、專有名詞與架構圖的視覺催眠，計算底層系統自由度與傳輸代價。

## 日常顯影：拆穿名字與圖案的視覺催眠

商博良留給我們的透鏡，在今天依然銳利。

大腦是天生的故事生成器。當事物冠上威嚴名字或畫上複雜架構圖時，我們的感官往往被表面張力吸住：

名片印著「全球生態協同副總裁」，投影片畫滿雲端中台與數據湖泊方塊。面對眩目的標籤與技術熱詞，請啟動「**商博良透鏡**」三步檢驗：

**第一步：剝離表面的視覺圖畫。**
不管圖標畫得多像雄鷹，不管報告辭令多玄妙，將圖畫還原為無情緒的符號 A 與符號 B，檢視其作為資訊載體的實質。

**第二步：數一數系統的自由度（符號庫有多大）。**
若公司有三十種威風頭銜，但團隊每日核心行為僅有推銷與催款兩件事，系統自由度只有 2。其餘二十八個名詞只是掩飾貧瘠的裝飾金甲蟲。

**第三步：比對符號量與實質任務的落差。**
若傳遞一個簡單決策，需發送上千封郵件、開三十場協調會（如同殘碑上的 1,419 符號對比 486 詞），算術落差便在報警：系統充斥著無意義的內部摩擦與自我拼讀。

名字從不等於現實，符號從不等於本質。當全世界對著華麗圖案下跪時，最勇敢的提問始於那個最枯燥的動作——別聽它唱得多好聽，拿出筆來，先數一數它到底有幾隻鳥。
