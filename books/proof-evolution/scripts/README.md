# 本書的重建與檢查工具

本目錄只服務《人類證明方法的演化》。從本書根目錄執行下列指令；不需要安裝 npm 套件，也不會連上網路。一般建置環境只需 Node.js 20 以上與 Python 3.9 以上。

```sh
python3 scripts/build-figures.py
node scripts/validate.mjs
python3 scripts/check-math.py
node scripts/build-reader.mjs
node scripts/verify.mjs
```

`build-reader.mjs` 先檢查稿件，再由 Markdown、閱讀器設定、CSS 與 JavaScript 產生 `web/index.html`。成品包含全書內容與所需樣式、程式，直接開啟即可離線閱讀。請修改來源後重建，勿直接編輯 HTML。輸出不含建置時間或電腦路徑，同一組來源會產生相同位元組。

`verify.mjs` 核對五張生成圖，再依序執行工具的針對性回歸測試、稿件結構檢查、九組基準算例重算、HTML 與來源的一致性檢查，以及產物完整性檢查。若要取得結構化報告，在指令後加上 `--json`。Python 執行檔預設為 `python3`，可用 `PROOF_BOOK_PYTHON` 環境變數指定。Node 會使用啟動此指令的執行檔。

## 稿件檢查的範圍

- 閱讀器與獨立章節清單必須依序列出 ch01 至 ch18；每章只有一個檔案，不能有漏章、重複條目或未列入清單的章節。
- 每篇只有一個一級標題，且標題層級不能跳級。每章正文至少有 1,800 個漢字；程式區塊、行內程式碼與註釋不列入深度計算。2026-10-07 的敘事契約已明確取消原 4,000 字底線；1,800 字只作缺稿警示，不能取代推理完整性與實際閱讀審查。
- 檢查占位文字、Unicode 數學格式、註釋的缺漏、重複與未使用定義，以及跨篇連結和標題錨點。
- 檢查 `outline.md` 的基準表與 `running-examples.md`、`maintenance.md` 中對應內容是否逐位元組相同。基準區塊以 `<!-- BEGIN BASELINE -->` 和 `<!-- END BASELINE -->` 標示；開頭標記後的換行不屬於表格，表格最後一個換行屬於表格。
- 在本儲存庫可讀到的閱讀器設定中檢查唯一識別碼 `proof-evolution-2026`。不存取外部個人檔案或登記簿。
- HTML 檢查使用 Python 標準函式庫的 HTML 解析器，確認所有 DOM 識別碼唯一、內部連結存在、18 章完整、沒有分離的資源，且內嵌程式與樣式符合內容安全政策的雜湊值。

## Markdown 與註釋

建置器使用已附在 `vendor/` 的 **marked 17.0.5**，支援一般段落、標題、強調、連結、行內程式碼、程式區塊、清單、引文與表格。來源中的相對 Markdown 連結會轉成單檔內部連結；所有本地連結的目標都必須列在 `web/book.config.json`。

本書使用下列註釋子集：

```md
這是需要來源支持的主張。[^ch03-source]

[^ch03-source]: 作者，作品，年份與章節。[來源](https://example.org/)。
    續行至少縮排四個空格。
```

註釋識別碼使用英文字母、數字、連字號、底線、句點或冒號，且第一個字元必須為英文字母或數字。重複引用同一註釋會有各自的返回連結。不同篇章的同名註釋不會共用錨點。註釋可含多段文字，但不支援註釋內的標題、巢狀註釋，或區塊內另行定義註釋。原始 HTML 與需要額外渲染器的 Mermaid／LaTeX 區塊會被拒絕。獨立圖片段落可引用 `book-src/figures/` 裡的靜態 SVG；其檔案須通過受限標籤與屬性檢查，不允許事件、腳本、外部資源或逃出圖目錄的路徑。圖片與圖說會內嵌於閱讀器，圖片 bytes 也納入重建一致性檢查。五張支援圖由 `build-figures.py` 生成，`--check` 可核對產物。圖例不含字型檔，使用閱讀裝置提供的中文字型。

數學重算涵蓋奇數和的歸納恆等式、合數形式的乘積加一、配方法、ε–δ 的不等式界線、貝氏算例、多重檢定與互動證明的誤差界。機率算例以有理數精確計算，再轉為顯示用小數；極限例把通用的不等式論證與有限數值回歸檢查分開列出。

## 實際瀏覽器檢查

若開發環境已安裝 Playwright 與 Chromium，可額外執行：

```sh
node scripts/browser-smoke.mjs
node scripts/browser-smoke.mjs --json --screenshots /absolute/path/to/screenshots
```

這個指令以瀏覽器離線模式開啟本地成品，檢查桌面與手機版面、章節切換、註釋往返、搜尋快捷鍵、進度保存、儲存空間不可用時的閱讀、列印全書，以及停用 JavaScript 的後備顯示。截圖為選用輸出。環境若提供 `CODEX_PRIMARY_RUNTIME_NODE_MODULES`，可用它尋找既有 Playwright；這不是一般建置的必要路徑。缺少瀏覽器時指令會明確回報未執行，且不會自動下載套件。

離線檢查不會抓取外部來源網頁，不能判斷史料是否可靠、引用是否支持主張，或所有自然語言敘述是否正確。數學重算不是形式證明系統；有限範例不能證成無窮命題。瀏覽器檢查是選定功能的 Chromium 回歸檢查，不能宣稱涵蓋所有瀏覽器或通過完整無障礙認證。同一家模型的編輯複核也不構成跨模型獨立驗證。
