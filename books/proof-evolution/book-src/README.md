# 人類證明方法的演化

## 從計算、論證與實驗，到形式驗證與 AI

一個公式連算四十次都對。第四十一次，你會不會相信它？

一個數已經精確到小數點後好幾位。再往下算，究竟是在改善答案，還是在追一個永遠不會結束的要求？

一個人找不到證明，一台電腦也找不到。這告訴我們答案不存在，還是只告訴我們他們沒找到？

這些問題，比「證明有哪幾種」更早。本書從這裡開始：我們原來相信的辦法做到了什麼，又在哪一步突然不夠用。方法不是排好隊等人背誦的名詞，而是在問題卡住時，讓人換一種走法的工具。

先跟著一個正方形走。它的石子可以精確數出，對角線卻帶來難纏的小數；更大的分母看似能解決問題，最後卻撞上不可能。往後，字母會擴大能計算的範圍，公理會改變問題的起點，機器會接手人無法逐一檢查的工作。每一步都留下新的追問：這次的答案，我們究竟憑什麼收下？

閱讀順序不是各文明依次交棒的歷史。古代材料有各自的用途與傳承；本書遇到原典沒有留下的步驟，會分清現代重建和當時實際記錄。實驗、統計與因果推論也不會因為出現在同一本書裡，就變成數學演繹的另一個名字。

正文以高中代數為起點。必要的符號在要用時說明，圖只補不易想像的關係；另一種證法、較長的驗算與原典細節放在附錄。初讀可以跟著問題走，不必先記住每個方法的名稱。
