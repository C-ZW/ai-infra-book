# 附錄 D　來源閱讀指南

本書的完整引註分列在各章末尾，並在需要它們的段落標出。每則註記盡量交代作者、作品、日期、版本、章節與網址，也說明該來源實際支持哪一部分。這份附錄提供進入原典與研究的路線，方便讀者從一個有興趣的案例開始核對。

來源沒有只靠名氣就能通用的等級。討論某篇文章說了什麼，原文是直接材料；討論某項方法最早何時出現，還需要比較其他材料與保存條件；討論一份形式證明是否可重做，論文之外可能還需要精確的程式與依賴。先想清楚問題，才能知道應該讀哪種來源。

## 找到差異時，怎樣提出可回應的問題

最有用的勘誤，會把主張定位到一句話、一道算式或一項來源。例如：「這個平方步驟只保證單向，為何後面當成等價？」比「這章不嚴謹」更容易回應；「此來源只有摘要，哪個段落支持新增的細節？」比把全部引註一概否定更有資訊。

來源之間若不一致，先比較它們談的是不是同一件事。事件年份、發表年份與後來完成形式化的年份，可以同時正確而不同。近似值、精確值、理論上界與實測值，也不能只按數字大小判斷衝突。把對象、條件與日期對齊後，剩下的分歧才是需要裁決的部分。

本書的方法與敘述同樣接受這種檢查。來源讓讀者能離開作者的語氣，直接追問一項具體理由；可重算的例子則讓讀者不用先相信作者，便能確認某一步是否成立。
