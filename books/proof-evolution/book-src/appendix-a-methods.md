# 附錄 A　證明與證據的方法圖譜

方法名稱可以幫助辨認推理，但不能替任何一段文字保證正確。本附錄把方法放回它要完成的工作：從前提推出結論、證明存在、排除可能、控制無限、檢查計算，或評估有限資料。這些工作有時結合在同一個論證中，不能只憑外觀分類。

以下的小例子採現代記法，都是為本書重寫的教學論證；它們不是對某位古人的原文翻譯。相關歷史與來源請沿章節連結閱讀。

## 從前提走到結論

| 方法 | 要完成的工作 | 一個簡短例子 | 必須檢查的地方 |
| --- | --- | --- | --- |
| 直接證明 | 沿可接受的推理，從假設推出結論 | 奇數的平方仍是奇數 | 對象的定義與運算規則 |
| 逆否命題 | 用 ¬B ⇒ ¬A 證明 A ⇒ B；此等價按古典邏輯理解 | 由奇數平方為奇數，證明整數平方為偶數時原數為偶數 | 原命題與逆命題不能混淆 |
| 反證法 | 假設欲證結論的否定，再導出矛盾 | √2 不是有理數 | 矛盾來自假設本身還是另有錯誤；所採邏輯允許的規則 |
| 分情況 | 把論域完整分割，逐一處理 | 連續兩整數的乘積為偶數 | 情況是否涵蓋全部對象，有無漏掉邊界 |
| 等價轉換 | 以雙向成立的條件代換原問題 | 非零係數的一次方程 | 不能把必要條件冒充充分條件 |

先把第一個例子做完。整數 m 是奇數，意思是有一個整數 k 使 m = 2k + 1。因此 m² = 4k² + 4k + 1 = 2(2k² + 2k) + 1。因為 2k² + 2k 仍是整數，m² 符合奇數的定義。這段證明沒有測試很多奇數；它只用了「任取一個奇數」必定具有的結構。

現在欲證「若整數 m 的平方是偶數，m 就是偶數」。假如 m 是奇數，前段論證已推出 m² 是奇數；一個整數不會同時是奇數與偶數。因此 m² 為偶數時，m 不能是奇數，而整數的奇偶分類沒有第三種情況，m 必須是偶數。這也提供[第三章](ch03-greek-deduction.md)反證 √2 無理性所需的奇偶引理。

反證中要細分兩種用法。從 A 導出矛盾，因而確立 ¬A，與從 ¬A 導出矛盾，進而確立 A，並非在每一種邏輯中都享有相同地位。前者建立否定；後者涉及雙重否定消去。討論直覺主義時，不能籠統說「它不准出現矛盾論證」。[第十章](ch10-construction-and-programs.md)說明這項差別與構造見證的關係。

分情況的正確性，則依賴分類本身。對任何整數 n，若 n 為偶數，n(n + 1) 帶有偶因數；若 n 為奇數，n + 1 為偶數，乘積仍帶有偶因數。因為整數只有奇偶兩類，論證完成。若有人只檢查正奇數與正偶數，就還沒有替負整數與零交代理由；「我心中想到的對象」不能取代命題寫出的論域。

## 處理無窮多個有限對象

| 方法 | 核心承諾 | 微型案例 | 常見缺口 |
| --- | --- | --- | --- |
| 數學歸納法 | 起點成立，成立性可從 n 傳到 n + 1 | 前 n 個正奇數和為 n² | 缺起點；歸納步暗用未證明的特例 |
| 強歸納法 | 可用所有較小情況來證明當前情況 | 每個大於 1 的整數都有質因數 | 使用的對象未必真的比較小 |
| 無限遞降 | 反例若存在，必引出更小反例，與良基性衝突 | 以最小反例排除某種整數結構 | 沒有明定下降量，或下降量可無限降 |
| 不變量 | 每一個允許步驟都保留某項性質 | 每次把整數加 2，奇偶性不變 | 只檢查某幾種操作，漏掉合法步驟 |

用本書的奇數和例子看歸納。設 S(n) 是 1 + 3 + … + (2n − 1)，n 為正整數。起點 S(1) = 1 = 1²。假設某個正整數 n 已滿足 S(n) = n²，則 S(n + 1) = S(n) + (2n + 1) = n² + 2n + 1 = (n + 1)²。歸納原理讓我們把這個起點和傳遞規則連起來，得到所有正整數的結論。這與「試了五次都成功」有不同的推理形式。

起點與步驟是兩份獨立責任。對錯誤主張「每個正整數都等於它自己加一」，若假設某個 n 的主張成立，兩邊加一，仍可形式上推出 n + 1 的主張成立。這種條件式傳遞沒有挽救任何一個起點。反過來，只證明 n = 1 成立，也沒有提供從一走向二的路。歸納不是把一份證據用兩種名字重複敘述。

質因數存在可以用最小者來證明。給定整數 N > 1，N 自己就是大於 1 的正因數，所以這類因數不為空。取其中最小者 d。若 d 不是質數，就有 1 < a < d 且 a 整除 d；因為 d 整除 N，a 也整除 N，這與 d 的最小性衝突。因此 d 是質數。這個論證依賴正整數非空子集具有最小元素。換成任意實數集合，不能照搬。

例如，正實數裡每一個 x 都有更小的 x/2，但正實數顯然存在。下降只在所選集合不允許那種無窮下降時才能產生矛盾。寫「一直變小，所以不可能」之前，必須指出變小的是什麼，以及為何它不能永遠變小。這項責任也出現在演算法的終止證明中：數值越來越小，和有限步之後一定停下，並不是同一句話。

不變量則適合證明某些目標到不了。從零開始，每次加二或減二，所有可達整數都能寫成 2k；因此不可能到達一。這沒有列出無限長的操作序列，而是證明每一個合法操作都保留偶數性。可是偶數性只是必要條件；遇到較複雜的操作規則時，不能看到目標也有同一不變量，就直接宣布目標一定可達。

## 證明「有」，以及交出「哪一個」

| 方法 | 怎樣支持存在 | 讀者還要問什麼 |
| --- | --- | --- |
| 直接構造 | 給出一個對象，並驗證它符合要求 | 所有定義條件是否都滿足 |
| 鴿籠原理 | 若對象比容器多，不能每容器至多一個 | 容器是否有限且分類涵蓋全部 |
| 雙重計數 | 以兩種合法方式數同一有限集合 | 兩次數的是不是相同對象、有無重複 |
| 一一對應 | 給出雙射，轉換計數或結構問題 | 兩個方向、單射與滿射是否交代 |
| 機率方法 | 證明隨機選擇中至少一個結果有目標性質 | 樣本空間、期望與存在結論之間的理由 |

想證明「存在一個偶數質數」，可以直接交出 2，然後檢查它是偶數且正因數只有 1 和 2。只寫出一個候選名字還不算完成構造；驗證條件的部分同樣必要。更一般的存在定理可能沒有這麼短的見證，卻仍要交代「存在」究竟由哪條理由支持。

鴿籠原理的一個例子是：把十三個對象分進十二個類別，至少有一類包含兩個以上。若每類至多一個，總數至多十二，與十三矛盾。這個論證不告訴我們是哪一類；若具體分類資料已知，逐一數就能找出來。存在、尋找效率與可取得的輸入資訊，是三個可以分開討論的問題。

雙重計數可以證明有限無向簡單圖的度數總和等於邊數的兩倍。數「頂點與相接邊組成的配對」：按頂點分組，每一組的大小是該頂點度數；按邊分組，每條邊有兩個不同端點，所以貢獻兩個配對。兩種分組都完整計算同一集合，結果必相同。這裡明定簡單圖，是為了不把迴圈的度數約定留給讀者猜。

若一張有限無向簡單圖有 m 條邊，把每個頂點獨立地以相同機率塗成兩色。每條邊有一半機率連到不同色的端點，因此不同色端點的邊數期望是 m/2。這個期望是所有有限塗色情況的平均；若每一種情況都小於 m/2，平均也必小於 m/2，矛盾。所以至少有一種塗色切開不少於一半的邊。證明是精確的存在論證，沒有聲稱一次隨機嘗試必然找到它。[第十章](ch10-construction-and-programs.md)還會追問這個理由如何轉成尋找的方法。

## 對付無限、模型與不可決定性

| 方法 | 工作 | 需要保留的界線 |
| --- | --- | --- |
| ε–δ 論證 | 對任意容許誤差，提供有效的輸入範圍 | 量詞次序；δ 不可暗中依賴稍後才選的 x |
| 反例 | 找一個符合前提卻違反結論的對象 | 反例只能推翻它實際碰到的全稱命題 |
| 模型 | 建立滿足公理的結構，檢查另個命題的真假 | 背景理論與相對一致性不能消失 |
| 對角化 | 構造一個與清單或候選判定器衝突的對象 | 構造必須合法，自我輸入須有定義 |
| 歸約 | 把一個問題轉成另一個問題，轉移可解性或困難性 | 轉換方向、可計算性與保留的答案 |

在[第六章](ch06-infinity-and-limits.md)的例子裡，f(x) = x²，考慮 x 接近 2。對任意 ε > 0，選 δ = min(1, ε/5)。若 0 < ∣x − 2∣ < δ，便有 ∣x − 2∣ < 1，因此 1 < x < 3，從而 ∣x + 2∣ < 5。於是 ∣x² − 4∣ = ∣x − 2∣∣x + 2∣ < 5δ ≤ ε。選 δ 的規則先於 x，且同時控制整段範圍內所有符合條件的 x，這才是量詞的工作。

反例尤其能顯示「觀察」與「全稱命題」的邏輯不對稱。命題說「每一個 n 都有性質 P」，只要找到一個合法的 n 沒有 P 就足以推翻；找到很多有 P 的 n，卻不能用同一種方式完成證明。不過，若命題是「某個分布下，大部分對象有 P」，單一反例便不構成反駁。首先讀清楚主張的量詞，才知道反例有多大力量。

模型論證同樣必須對準命題。若公理集合 T 的某個模型使命題 φ 不成立，則在相關推導規則的健全性前提下，T 不能推出 φ；若 T 能推出 φ，φ 就應在每個 T 的模型成立。模型存在本身可能要在更強的背景數學裡證明，因此這種工作通常交代的是相對關係。[第七章](ch07-axioms-and-models.md)與[第八章](ch08-logic-and-foundations.md)分別從幾何與形式語言說明。

對角化則讓構造者針對一整份候選清單設計差異。以二元無限序列為例，若聲稱列出全部序列，便把第 n 個序列的第 n 位翻轉，得到一條新序列。它與每一個列出的序列至少在對應位置不同，所以清單不完整。這個案例選擇序列，不先把序列翻成小數，因而不必處理 0.0111… 與 0.1000… 表示同一個數的問題。轉到停機問題時，還要交代程式編碼、假設判定器會停止，以及被構造程式的行為；完整責任見[第九章](ch09-incompleteness-and-computation.md)。

## 檢查機器與評估世界

| 類型 | 可交付的檢查材料 | 結果仍依賴什麼 |
| --- | --- | --- |
| 有限窮舉證明 | 有限化的理由、完整枚舉規則、每類的檢查 | 歸約的正確性與是否真的涵蓋全部 |
| 證書驗證 | 候選答案附帶可獨立檢查的證書 | 證書格式、驗證器及其使用的規則 |
| 形式化證明 | 明定命題、相依公理、可檢查的證明物件 | 命題翻譯、核心、依賴與執行環境 |
| 互動證明 | 提問規則、回應與接受條件 | 完整性、健全性誤差及挑戰的隨機性 |
| 受控實驗 | 測量、介入、對照與可追查的程序 | 測量品質、輔助假設與外推範圍 |
| 統計推論 | 資料、抽樣模型、估計或檢定程序 | 模型、選擇機制、誤差與先驗等條件 |
| 因果推論 | 對介入的明定問題及識別論證 | 混雜、處置定義、資料與設計假設 |

同一份計算輸出可能在不同工作中扮演完全不同的角色。程式試過一百萬個輸入，若問題仍有其他合法輸入，這是廣泛測試。若已證明所有可能情形都可歸約到那一百萬類，而且逐類檢查可靠，計算就能成為證明的一部分。數量大不大，無法替代「全部是否已被涵蓋」這個問題。[第十四章](ch14-computer-assisted-proofs.md)把歸約與檢查分開說明。

形式化證明也有類似區別。核心接受命題「所有符合假設 A 的形式物件都具有 B」，足以交代一項精確數學關係；實際系統是否符合 A，仍可能需要另做測量、建模或程式對應。把這項工作指出來，沒有削弱形式驗證的價值，而是讓它的價值可以被正確使用。詳見[第十五章](ch15-proof-assistants.md)。

實驗與統計面對的是另一種有限性：我們只得到特定設計、儀器和環境中的資料。增加資料可能減少某些抽樣誤差，卻不會自動修正系統性偏差或錯誤的因果問題。[第十一章](ch11-experiment-and-evidence.md)到[第十三章](ch13-causality-and-replication.md)討論如何把這些依賴變成公開可批評的部分。方法成熟的標誌之一，就是它能準確說明自己交出的保證。
