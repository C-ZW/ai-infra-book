# 第三章　希臘的演繹秩序：圖形、反證與公理

證明一個結論，和組織一整本可供查驗的數學書，難題不同。前者要找到通往終點的路，後者還要安排道路如何接起來：哪些用語先說清楚，哪些操作可以直接開始，哪些結論必須等前面的工作完成後才能引用。《幾何原本》的力量，很大一部分就在這種組織。讀者接受一個命題時，不只得到一句答案，也得到追溯它所依據之處的方向。

歐幾里得一般被置於約公元前三百年的亞歷山卓；傳世《幾何原本》有十三卷，內容包括平面與立體幾何、比例及數論。[^ch03-edition] 這樣的概略定位不等於我們握有他的寫作現場。今天閱讀的版本經過抄傳、編輯和翻譯；本章使用具名現代英譯，並在需要時改寫符號。要欣賞書中的演繹安排，不必把它想成某位作者憑空創造全部數學，更不必把它當成人類此前從未提出理由的證據。

## 一個三角形，幾種不同的起點

《幾何原本》第一卷先列定義、公設與共同概念。定義說明點、直線、圓、三角形等用語；公設允許某些幾何操作或關係，例如連接兩點、延長線段、以中心和半徑作圓；共同概念則列出相等量之間可用的關係。[^ch03-edition] 用語先固定：本書以「公理」作現代總稱，指推理接受的基本陳述；「公設」與「共同概念」則保留歐幾里得文本本身的分類，不是再往上或往下的一層新前提。

這三種文字的工作並不完全相同。說明「等邊三角形」是三邊相等的三角形，還沒有告訴我們任何一條給定線段上都能造出它。准許以指定中心和半徑畫圓，也還沒有直接說出兩個特定圓會在哪裡相交。定義提供用語，操作要求提供能做的事，證明則必須把它們接成足以完成目的的理由。

第一卷第一命題正好展示這項分工：在一條給定線段 AB 上作等邊三角形。以 A 為中心、AB 為半徑作圓，再以 B 為中心、BA 為半徑作圓，取兩圓的一個交點 C，連接 AC 與 BC。因為 C 與 B 在第一個圓上，AC = AB；因為 C 與 A 在第二個圓上，BC = BA。兩者都等於同一條線段的長，於是三邊相等。[^ch03-i1]

![兩個圓的半徑都取 AB，交點 C 與兩端相連成三角形。此圖只定位作圖步驟；交點存在的依據仍須由正文交代。](figures/euclid-circles.svg)

這不是拿尺量出三條邊大致相同。相等來自圓的定義和作圖條件；最後一步則依靠「等於同一量的各量彼此相等」這項共同概念。[^ch03-common] 若讀者懷疑 AC 為何等於 AB，就可以回到第一個圓；若懷疑兩個相等關係能否串起來，就可以檢查共同起點。這種可追溯性，比結尾寫一句「完成」更有實際作用。

今天一些版本在旁邊直接列出所用定義、公設和命題的編號。這些指路標記方便查閱，但不應全都算成原作者逐項留下的註記；Joyce 的電子版特別交代，旁註是閱讀輔助。[^ch03-i1] 文本有一套依存關係，和版本把這套關係標註到多細，又是兩個層次。後來的編者也在參與讓理由更容易接受檢查的工作。

然而，推理中有個位置值得停下來：那個交點 C 為何一定存在？圖上兩個圓顯然交會，文本卻沒有從列出的基本要求單獨證成這件事。現代編者與後來的形式檢查研究都指出，若要求每項依據明確列出，就必須補充相交、連續性或相關幾何條件。[^ch03-i1][^ch03-beeson] 這不表示等邊三角形不能作出，而是提醒我們，古代讀者所接受的圖形常識，比書首明列的句子多。本章先在通常的歐氏平面中接受這對圓有交點，繼續檢查三邊相等的理由；若要只靠一份明列的公理清單完成形式證明，就要另外交代交點存在的依據。此處標記的是依據有沒有寫全，不是推翻作圖結果。

我們因此要區分「有系統的演繹著作」與「所有步驟只按明列規則執行的現代形式系統」。前者已經能讓大量依存關係公開，仍可能讓圖形承擔未明說的資訊。後者如何建立，留到[第八章](ch08-logic-and-foundations.md)。如果拿後者的完整要求當成歷史閱讀的唯一標準，就容易只看見缺口，反而看不見那些已經被安排得非常清楚的依據。

## 圖形讓一般關係有了位置

AB 是紙上的一條具體線段，第一命題卻要處理任意給定線段。一般性從哪裡來？不是因為這條線畫得特別中立，而是因為推理只使用它是線段、圓以它作半徑等被允許的關係，沒有利用印刷長度剛好三公分。若把圖放大、縮小或轉向，使用的關係仍然相同，論證便不需要重新發明。

圖上的字母也讓不同步驟能說同一個對象。AC 在第二段仍是前面那條 AC，讀者不必靠形容詞猜測。這種固定指認很像[第一章](ch01-why-prove.md)給點陣編列號和行號：它讓局部理由可以接合，並讓批評落到某一個位置。一幅圖可以看成有標記的推理工作面，既協助思考，也接受質疑。

但畫面中的所有特徵並不都有同等資格。某條線看來比另一條長，未必是題目給定的條件；三點看來共線，未必已經證明。閱讀幾何論證時，一個有效的習慣是問：這項關係是題目規定、操作保證、已證命題推出，還是只因畫得像？交點 C 的問題，正是這個習慣伸向最熟悉的畫面後得到的收穫。

亞里斯多德在《後分析篇》提出的是另一種工作：分析什麼樣的起點與推理能構成論證知識。他要求論證的前提和結論之間有適當的優先關係，也討論定義、假設與不能再由同樣方式證明的起點。[^ch03-posterior] 這是哲學性的論證說明，不是逐頁描述《幾何原本》的寫作程序。我們可以比較兩者，也應讓實際數學文本保留自己的形狀。

例如，剛才的等邊三角形需要作圖、指定對象、調用圓的性質，再把等量連起來。若只把它縮成一個抽象的三段論口號，操作與圖形的工作便消失了。要問古希臘的論證如何成立，哲學文本是證據，數學文本也是證據；不該先用其中一類替另一類規定全部答案。

## 任何一張質數名單，都可以被超過

《幾何原本》的依存結構並不只服務幾何。第九卷第二十命題談質數，其意思是：質數比任何給定的有限一批質數還多。[^ch03-ix20] 這不是用很長的數表表示「目前還沒找到終點」，而是對任何可能的有限名單，提供一個不能封住名單的理由。

先把本章的數說清楚。自然數在本書採包含零的慣例，即零、一、二、三等；本節的 n 以及質數都限於正整數。質數是大於一、正因數只有一與自身的整數，例如二、三、五。若一個整數是另一個整數的整數倍，就說前者能被後者整除。以下推理使用通常的整數加法、乘法與整除性質；不把紙上的線段長度當成現代整數本身。

先證一個準備結果：每個大於一的整數 N 都有質因數。考察 N 的所有大於一的正因數，這些因數至少包括 N 自己，而且都在二到 N 的有限範圍中，所以有最小者 d。若 d 不是質數，它就能分成 a 乘 b，其中 a、b 都大於一，也都小於 d。由於 d 整除 N，a 也整除 N；這便得到一個比 d 更小、又大於一的因數，違反 d 的選擇。因此 d 是質數。

這個小證明補足了後面真正要用的依據。它沒有假定每個整數的質因數分解唯一，也不需要先知道所有質數。《幾何原本》第七卷第三十一命題給出相應結果，以不斷取得更小因數的路徑說明最後必須遇到質數。[^ch03-vii31] 本章改用有限因數集合的最小者，讓停止的理由更容易逐項核對。

「最小」在此有確定的範圍。我們是在有限個正整數因數中選取，不是在任何可能的數量之中取最小。若改問最小的正分數，任取一個還可以再除以二，就沒有最小者。因而，從因數中找出質數的辦法，不只是一般的「一直往下找」口訣；正整數的離散性與這次有限的候選範圍，共同保證了它可行。

現在任取一張非空的有限質數名單，記成 p₁、p₂，一直到 p_n。把名單中的數全部相乘，得到 P，再令 N = P + 1。N 大於一，因此剛才的準備結果保證它至少有一個質因數 q。問題只剩：這個 q 能不能也在原來的名單上？

若 q 在名單上，q 就整除乘積 P；它又是 N 的因數，所以也整除 N。兩個 q 的整數倍相減，仍是 q 的整數倍。因此 q 必須整除 N − P，也就是一。但 q 是大於一的正整數，它不可能整除一。這個假設導致矛盾，所以 q 不在原名單上。任意一張有限名單之外，都還有質數。

為什麼偏偏加一？因為一沒有大於一的正因數，所以任何舊質數都無法同時整除 P 與 P + 1。如果隨手改成加二，原名單只要含有二，二就會同時整除 P 與 P + 2，原來的排除理由便失效。證明中的這個小常數不是裝飾，它刻意讓所有候選的共同因數都撞上同一個不可能。理解這個選擇，也讓讀者知道哪些變形需要重新證明。

因為二本身就是質數，質數集合不是空的；若全部質數只有有限多個，就能把它們寫成前面那種非空名單，而論證又會找出名單以外的一個。這與「全部已在名單內」衝突。所以質數無限多。證明沒有按順序列出所有質數，也沒有預先指定下一個新質數是多少；它確保任何有限的封口都會失敗。

這份證明保留歐幾里得的核心思路，表示方式則是現代改寫。原文以給定的若干質數及它們的最小公倍數加上一為出發點，再區分所得的數本身是質數或有質因數的情形；本章用乘積作共同倍數，直接選取一個質因數。[^ch03-ix20] 相同的數學骨架不必假裝穿著同一套歷史語言。

這裡最常見的誤讀，是說「所有已知質數相乘再加一，就會得到質數」。論證從來不需要這句話。依照一份短名單，實際算出來的是：

```text
2 × 3 × 5 × 7 × 11 × 13 + 1 = 30031
30031 = 59 × 509
```

三萬零三十一是合數，已足以推翻那句誤讀。真正成立的是：原名單中的任何一個質數都不能整除它，所以它的質因數必定落在名單之外。新數是否質數，是一回事；是否迫使新質因數出現，是另一回事。把這兩件事分開，讀者才掌握了證明的關節。

## 反證不是宣布對方荒謬

上面的論證在一個關鍵位置暫時假定 q 在名單中，追出 q 必須整除一，再撤回那個假定。這叫反證：在共同接受的背景下，假定要排除的主張成立，從它導出不可能同時接受的結果。矛盾必須由推理產生，不能只是「我覺得很奇怪」，更不能用反對者不喜歡某個結論當作完成。

導出矛盾後，還須檢查它究竟來自哪裡。如果中途偷偷除以零，矛盾只暴露那次非法運算，不能替原先的結論作證。若背景條件本來就互不相容，也不能把責任全推給臨時加入的假設。反證的力量，取決於其餘依據與每一步轉換都經得起核對。

更清楚的例子是 √2 不能寫成兩個整數的比。先界定主張：√2 指平方等於二的正實數；有理數是可以寫成 a/b 的數，其中 a、b 是整數且 b 不為零。要證明 √2 是無理數，就是排除所有這種整數比，不只是找不到一個足夠準的小數。小數寫不完也不足以證明無理：三分之一的小數需要不停寫三，它仍然明白地是整數比。要排除有理性，就必須處理整數比的全部可能，不能只看某段展開是否出現熟悉的循環。反證在這裡讓所有可能的分子分母一同受到限制。

我們使用的關鍵性質是：整數若平方為偶數，原數就是偶數。為什麼？任何非負整數不是 2k，就是 2k + 1，其中 k 也是非負整數。第二種是奇數，它的平方為 4k² + 4k + 1，等於 2(2k² + 2k) + 1，仍是奇數。因此奇數不可能有偶數平方。對本節需要的正整數，結論已經足夠。

現在反過來假設 √2 = a/b，並令 a、b 都是正整數，沒有大於一的共同因數。正數比例可以把符號調成全正；分子與分母若有共同因數，就同除以它直到不能再約分。這個過程不會無窮繼續，因為分母每次嚴格減小，卻始終是正整數。於是取最簡分數不是無故新增的限制。

等式兩邊平方，得到 a² = 2b²。因此 a² 是偶數，剛才的性質說明 a 也是偶數，可以寫成 a = 2k。代回原式，便有 4k² = 2b²，約去二後得到 b² = 2k²。這表示 b² 是偶數，於是 b 也必須是偶數。分子分母同時被二整除，與一開始已約到最簡的條件矛盾。

因此，不可能有這樣的整數比，√2 是無理數。每一步都在通常的整數算術中完成；矛盾具體落在共同因數二。假如省略最簡分數的條件，最後得到 a、b 都是偶數就沒有矛盾，例如二與四本來就都偶數。證明的結尾能否站得住，常取決於起點那句看似例行的限制有沒有交代。

亞里斯多德在《前分析篇》第一卷第二十三章，提到假設正方形對角線與邊可公度，會導致奇數與偶數的衝突。[^ch03-prior] 這是古代反證思路的直接文字見證，並不是本章現代分數證明的逐行抄本。本章也不據此指定某個發明者。把現代版本能做的推導，與古代作者實際說出的話分開，才不會讓可靠的數學結論替不可靠的歷史故事背書。

「可公度」的幾何意思是，兩條長度有一個共同的小單位，各自都是它的整數倍。若邊長是 b 份，對角線是 a 份，兩者比就是 a/b；反過來，若比為 a/b，把邊分成 b 份，其中一份也就能整數次量完對角線。因此整數比與共同尺度在這裡接起來。證明排除的，是共同尺度的存在，並沒有說對角線不能畫、不能測量，或不能被近似。

[上一章](ch02-tablets-and-algorithms.md)的 q 仍然很有用。無理性沒有讓近似值失去價值，也不會因為近似值越算越準而消失。有限小數本身可以寫成整數比，所以只要它聲稱精確等於 √2，就違反了剛才的結論；若它聲稱誤差在某個界線之內，就應接受另一種檢查。把兩種主張混在一起，才會讓精確證明和數值工作看似互相競爭。

## 依據公開以後，批評也有了秩序

質數無限多的證明借用質因數存在；質因數存在借用有限正因數可以取最小者。無理性證明借用奇偶性質與分數約分；奇偶性質再借用整數分成偶數和奇數的規則。把這些依存寫出來，能避免論證偷偷繞回待證結論，也能讓不同讀者從自己尚未接受的地方接手。

公開依據不是保證讀者永遠不會看錯。有人可能記住乘積加一，忘掉質因數；有人可能記住分子分母都偶數，忘掉最簡分數。文字的秩序提供糾正的辦法：逐步追問哪個結論真正被推出、哪個假定正在使用。證明不是只供存放的成果，也是可反覆使用的批評工具。

圖形的交點問題則表明，批評可以改變整本書需要明說的起點。發現未列出的條件，並不迫使我們在「全書完美」與「全書毫無價值」之間二選一。可以保留有效結構，補上缺口，再問新的陳述是否足夠。這種修訂使演繹著作保持可讀、可教，也保持可爭辯。

《幾何原本》把許多理由組成可追溯的次序，但世界上的理由沒有因此只剩一種書寫格式。[下一章](ch04-plural-traditions.md)要讀的注釋、比例解釋與幾何算法，會把相同的追問放到別種文本中：哪一步有依據，依據如何使運算成立，讀者能在哪裡提出異議。判斷一段理由，仍須回到它實際做出的工作。
