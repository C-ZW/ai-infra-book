# 第十六章　只檢查一點，也能有把握嗎：互動證明與零知識

把一份證明交給別人，通常也把推導過程交了出去。讀者可以逐行查看，把它轉寄，或隔年再讀。但設想另一種要求：有人知道兩張網路圖其實只有節點名稱不同，希望使對方相信這件事，卻不想直接交出名稱的對照表。若完全不提供理由，對方憑什麼相信？若提供完整對照，原本想保留的資訊又已經送出。

一九八五年，Goldwasser、Micali 與 Rackoff 發表的論文把「如何傳遞證明」重新列為研究問題：驗證者可以隨機提問，證明者依序回答，而我們分析整個互動程序的保證。這裡接受的對象仍是明確的數學命題；改變的是檢查方式與允許的錯誤，而非命題的真假由擲硬幣決定。[^ch16-gmr85]

這條路要求我們拆開幾個原本容易混在一起的問題：真命題能否通過？假命題有多大機會混過去？對方通過之後，我們能否說他知道某個答案？互動又透露了多少資訊？同一個協定必須分別回答，不能用其中一項保證代替其餘三項。

## 先送出圖，再接受挑戰

以下使用有限、無自環、無重複邊的無向圖。「圖同構」表示存在一個節點的一對一對應，使兩個節點相連，恰好等價於對應後的兩個節點相連。圖上畫出的角度與長度沒有作用。對應必須涵蓋全部節點，而且保留相連與不相連的關係；只把幾條邊對上，還不足以證明同構。

公開的圖是 G₀、G₁，節點數同為 n。證明者知道一個同構 f：G₀ → G₁。這個 f 是命題成立的「見證」：把它交出來，驗證者就能逐一檢查。但現在要安排一種不用直接傳送 f 的問答。下面是經典圖同構協定的重新標記版本；GMW 的原論文與 Bellare、Goldreich 的知識證明論文均載有此基本構造。[^ch16-gmw][^ch16-pok]

每一輪，證明者先均勻隨機選擇一個節點排列 r，把 G₀ 的節點重新命名，得到 H = r(G₀)，再把 H 傳給驗證者。收到 H 之後，驗證者才擲一枚理想公平硬幣，決定挑戰位元 b 是 0 還是 1。他要求證明者交出從 G_b 到 H 的同構。

若 b = 0，證明者交出 r。若 b = 1，證明者交出 r ∘ f⁻¹。這個複合對應的順序是先用 f⁻¹，把 G₁ 的節點送回 G₀，再用 r 送到 H。驗證者只須檢查收到的對應是不是要求的同構。若有節點漏掉、重複，或任一對節點的相連關係不符，就拒絕；全部符合才通過這一輪。

用三個節點可以把每一步攤開。令 G₀ 的節點為 1、2、3，邊為 1—2 與 2—3；G₁ 的節點為 a、b、c，邊為 a—c 與 c—b。它們都只是一條含三個節點的路徑。取 f(1) = a、f(2) = c、f(3) = b。這個例子很小，任何讀者都能找到 f，因此沒有保密難度；它只用來查看協定到底檢查什麼。

假設這一輪抽到 r(1) = v、r(2) = u、r(3) = w。送出的 H 就有 u—v 與 u—w 兩條邊。兩種挑戰的回答如下：

| 挑戰 | 交出的節點對應 | 原圖的兩條邊變成 | 原圖唯一不相連的一對變成 |
| --- | --- | --- | --- |
| b = 0 | 1 → v，2 → u，3 → w | v—u、u—w | v、w |
| b = 1 | a → v，c → u，b → w | v—u、u—w | v、w |

每欄都能直接核對。H 的確含有兩條指定的邊，v 與 w 也確實不相連。若證明者把第一列的 2 改送到 v，就不再是一對一對應；若把第二列的中心 c 送到 v，即使所有節點仍各出現一次，也會把相連關係弄錯。驗證者檢查的是一個可計算的條件，不必評估說話者是否自信。

## 假命題為什麼每輪至多成功一半

先看完備性。在本章的協定中，若兩圖確實同構，而且證明者持有 f、雙方照規則操作，那麼兩種挑戰都有正確答案，每輪必定通過。這稱為「完美完備性」。此處的完備性是互動協定對真輸入的接受保證；它與[第八章](ch08-logic-and-foundations.md)所談、連接語法與語意的邏輯完備性，使用同一個譯名，但定義不同。

再假設 G₀ 與 G₁ 不同構。證明者可能作弊，可能用任意策略選 H，也可能具有無限計算能力。只要 H 已經送出，它就不可能同時與兩張公開圖同構。因為若 φ₀：G₀ → H 與 φ₁：G₁ → H 都存在，φ₁⁻¹ ∘ φ₀ 就會給出 G₀ 到 G₁ 的同構，與假設矛盾。

所以，固定任何已送出的 H，兩種挑戰至多有一種可以正確回答。驗證者在此時才獨立、均勻選擇 b，作弊者通過的機率便至多為 1/2。這是「健全性錯誤」的上界：當待證命題為假，任意證明者使指定驗證者錯誤接受的機率上限。它不是對某個可疑人物的心理判斷，也沒有假定作弊者沿用誠實者的隨機方法。

重複二十輪，規定每輪通過才繼續，全部通過才接受。重點不只是說「硬幣擲了二十次」，而是對每一段可能的先前紀錄，下一輪的 H 固定之後，挑戰仍須不可預知、均勻且獨立於作弊者。即使作弊者根據過去所有問答調整策略，條件成功機率仍至多 1/2。沿著每輪成功的條件機率相乘，得到：

```text
P(二十輪全部通過 ∣ 兩圖不同構)
≤ (1/2)²⁰
= 1/1048576
≈ 0.00009537%。
```

這個界限有明確的方向。它沒有說，看見二十輪通過之後，「兩圖不同構的機率」就等於這個數。要倒轉條件，仍須處理[第十二章](ch12-probability-and-statistics.md)討論的先驗資訊與條件機率。協定保證的是假命題受到這套程序檢查時，很難通過。

先後順序也是證明的一部分。如果驗證者先公布 b，作弊者就能直接把 G_b 重新命名成 H，再交出自己剛做的對應；不論兩張公開圖是否同構，都能成功。若挑戰永遠是 0，同樣失去作用。增加輪數不能修補這種程序改動。數字小到什麼程度，必須連同它依賴的隨機性與訊息順序一起讀。

還有一個容易漏掉的限制：剛才的上界針對「兩圖不同構」。若兩圖其實同構，只是證明者起初沒有得到 f，他可能在互動中算出一個同構。不能直接套用剛才的論證，說所有「不知道答案的人」也只能猜中一半。「知道」需要另一個定義，稍後才處理。

## 能夠模擬的紀錄，透露了什麼

通過檢查與保留資訊是兩個問題。即使每輪只交出一張公開圖到 H 的對應，直覺上似乎沒有交出 f，也還不能據此宣布零知識。零知識需要比較兩個程序：一個真的與持有見證的證明者互動；另一個只有公開輸入，卻能產生相同、接近，或在指定計算能力下無法區分的驗證者視野。後一個程序稱為「模擬器」。這項比較必須對命題成立的輸入定義；它不是要求每個假命題也能通過。[^ch16-gmr89]

先只考慮照規則提問的誠實驗證者。模擬器不知道 f，但可先擲硬幣決定 b，再均勻隨機選一個排列 s，把 G_b 重新命名成 H，最後輸出紀錄 (H, b, s)。整份紀錄一定通過檢查，因為它正是把一張圖重新命名後，附上剛用過的對應。

為什麼這份紀錄的分布和真實互動相同？在真正互動中，b = 0 時回覆的 r 是均勻排列。b = 1 時，回覆為 r ∘ f⁻¹；與固定的 f⁻¹ 複合，會把所有排列一對一地重新排列，因此回覆仍是均勻排列。兩種情況下，H 都由該回覆作用在 G_b 上得到。再加上 b 本身均勻，兩個程序產生每種三元紀錄的機率完全相同。

這個理由不要求不同排列總會產生不同的 H。有些圖具有對稱性，兩個不同排列可能得到相同標記的圖；我們比較的是包括回覆對應在內的完整紀錄，而且「與固定排列複合」仍然是一對一運算。因此圖的對稱性不會破壞上述分布計算。這也說明，光看 H 好像夠亂，還不足以代替模擬器證明。

每輪都使用新的獨立排列，誠實驗證者每輪也重新擲硬幣時，可以逐輪模擬完整紀錄。驗證者的相關隨機位元已經包含在 b 裡；他的最後判定又由紀錄決定。於是本章完成的是這個理想協定的「誠實驗證者完美零知識」論證：不靠 f，也能有效率地產生完全相同的可見資訊。

「誠實驗證者」這個限定不能省略。若對方看了 H 才以特殊方法選 b，而非照規定擲公平硬幣，先選 b 的簡單模擬器便未必重現他的行為。GMW 原論文進一步處理偏離協定的有效率驗證者；那需要更強的模擬論證。本章沒有展開它，因此上述逐步推導只支持誠實驗證者版本。[^ch16-gmw]

完美零知識要求分布完全相同；統計零知識容許分布有受控而極小的差異；計算零知識則容許分布不同，但要求受限於指定計算資源的觀察者無法有效區分。第三種保證常與計算困難假設一起出現。這三種定義談的是互動增添的資訊，不是宣稱公開圖本身絕不可能使人找到同構。三節點例子中，答案原本就能一眼看出，模擬論證仍然成立。[^ch16-gmr89]

## 為什麼一份錄影不能代替親自提問

模擬器能自己做出成功紀錄，看起來像是摧毀了證明。其實它揭示了不同的憑據：現場驗證者知道自己是在收到 H 之後才隨機選 b；旁觀者收到一份紀錄，無法僅憑內容判定兩者的生成順序。模擬器的先選 b，正是現場作弊者不享有的自由。

因此，這種互動紀錄與[第十四章](ch14-computer-assisted-proofs.md)可供任何人重查的演繹證書不同。若兩圖不同構，預先選定挑戰的程序仍能製作局部合法的紀錄；它無法保證在真正未知的挑戰到來時答對。接受的理由包含參與者實際控制了隨機挑戰這件事。把整段文字交給第三人，沒有自動把這項控制也交出去。

這也讓「沒有額外資訊」的意思更清楚。模擬器不是神奇地從空白製造真理；它拿到公開圖，利用公開圖就能做的重新命名，重現互動留下的痕跡。對真輸入，這些痕跡沒有提供比模擬器本來能生成的更多計算能力。至於某個圖代表哪一家機構、檔名暴露什麼、回覆耗時是否受實作細節影響，都不是這個純數學模型已經涵蓋的資訊。

## 知識可以用抽取來界定

回到「證明者知道同構」的說法。知識證明不企圖讀取人的內心，而是訂出操作性的要求：若某個證明者能以高於指定基準的機率通過，就應存在一個抽取器，利用對這個證明者的特定存取方式，有效率地取得見證。Bellare 與 Goldreich 特別說明，抽取器的運行時間需要與成功機率超過知識錯誤門檻的程度一起界定，不能只說「偶爾通過，所以知道」。[^ch16-pok]

圖同構例子提供了抽取的代數核心。假設我們能讓同一個 H 接受兩種不同挑戰，並取得兩個合法回覆 φ₀：G₀ → H、φ₁：G₁ → H，那麼 φ₁⁻¹ ∘ φ₀ 就是一個公開兩圖之間的同構。這個計算只需要反轉與複合排列。三節點表格也能驗算：1 先到 v，再沿第二列反向回 a；2 到 u 再回 c；3 到 w 再回 b。

但正常驗證者每輪只會提出一種挑戰。他不能因為抽取器的論證使用兩份相關紀錄，就聲稱自己從單一回覆拿到了 f。抽取器常在理論模型中回到同一個中途狀態，改給另一個挑戰；這種重繞或黑箱存取，比一次真實互動具有更多控制。要證明完整的知識性，還要證明抽取程序確實能取得所需的相關回答，並符合效率與成功率要求。上面的複合運算展示核心機制，並非省略這些條件的通用定理。

同一個小計算也指出一種具體改動的後果。若誠實證明者為省事，反覆使用完全相同的 H 與同一個 r，兩次遇到不同挑戰時，就會直接交出 r 和 r ∘ f⁻¹。收件者把兩者複合，便能重建 f。原協定每輪重新隨機化的要求，不能在討論資訊保留時刪掉。證明一個程序具有零知識性，沒有證明它的所有近似版本也具有零知識性。

這裡沒有矛盾：模擬器證明普通互動能看到的內容沒有增加指定資訊；抽取器則在另一種存取模型下，描述高成功率的證明者必須具備什麼可用能力。完備性、健全性、零知識性與知識抽取，分別限制真輸入、假輸入、驗證者所得資訊，以及證明者可被取出的見證。四個定義的量詞與資源不同，不能只用「可信」一詞帶過。

## 問答、短見證與抽查，是不同的資源安排

上述假命題每輪至多通過一半的證明，沒有假定某道計算題很難。即使作弊者算力無限，不同構的兩張圖也無法同時同構於同一個 H。這是資訊理論層級的健全性保證，條件在理想隨機性與訊息順序。另一方面，要把零知識構造推廣到一般 NP 問題，經典結果會使用密碼學假設；GMW 的一般構造可建立在單向函數存在之上。單向函數大意是容易計算、但對隨機產生輸入所得的輸出，受限的演算法很難找回任一原像；這項存在性是明列的假設。[^ch16-gmw]

還有些系統的健全性只限制具有多項式時間的作弊者，並依賴指定的計算困難假設；這類系統通常稱為 argument，可譯為計算論證。這個名稱區分的是保證範圍，不是認真程度。無限算力的對手可能打破它，而這不違反原先只對受限對手建立的定理。另一方面，誠實證明者拿到見證後能快速作答，並不表示健全性也只對快速作弊者成立。圖同構例子正好把兩者分開：持有 f 時回覆很容易，假輸入仍連無限算力都不能跨過每輪的一半上界。[^ch16-gmw]

NP 可以從短見證理解：對一個長度為 n 的輸入，若答案是「是」，便有長度受 n 的某個多項式限制的見證，由確定性演算法在多項式時間內檢查。假輸入則不應有任何能通過的見證。這沒有保證見證容易找到。圖同構的完整節點對照便符合這種安排。這裡的「有效率」是計算複雜度的漸近尺度，不保證每個具體輸入在實際機器上很快。[^ch16-gmr89]

IP 容許驗證者使用隨機性並反覆問答，仍限制他的總計算時間為多項式，卻不要求一般定義中的證明者也受相同時間限制。Shamir 的結果 IP = PSPACE，說這類互動證明可以處理的判定問題，正好等於多項式空間可判定的問題。它不是說所有證明都能快速找到，也不是說實際世界所有問題都已經容易計算。[^ch16-shamir]

PCP 則把注意力轉向一份已固定、可隨機存取位置的編碼證明。Arora、Lund、Motwani、Sudan、Szegedy 的定理指出，每個 NP 語言都可使用多項式時間驗證器，只消耗對數量的隨機位元，讀取固定常數個證明位元：真輸入有一份對所有隨機選擇都通過的證明；假輸入的每份候選證明，被拒絕的機率至少為一半。[^ch16-pcp]

這不是隨手翻一本普通證明的幾頁。若百萬行文字只有一行偷偷加入錯誤假設，均勻抽一行很容易漏掉。PCP 定理所保證的是特別編碼後的證明系統，連同能抓出不合法全局結構的局部檢查。固定常數個位元也不是說驗證器不讀原問題、不做其他計算，更沒有保證提供者的秘密受到保護。

圖同構協定同樣沒有「只讀常數個位元」的性質。每輪雖只選一個二元挑戰，驗證者仍須檢查完整節點對應及圖的相連關係。互動次數、每次讀取量、證明長度、搜尋時間與資訊揭露，都是可以分別計算的成本。把它們統一稱為「很短的證明」，反而會使真正得到的改進消失。

證明的方法到了這裡，連「交出理由」都不再只有一種形式。有人交出可反覆閱讀的推導，有人交出機器可查的證書，有人參與一場順序與隨機性都受約束的問答。要判斷一次接受是否有根據，便得連程序的規則一起檢查：結論在什麼情形成立，錯誤界限對誰成立，資訊保證又容許誰做什麼。下一章的[AI 搜尋與形式驗證](ch17-ai-and-proof.md)會把這種分工帶回另一種場景：能快速產生答案的系統，應該交付什麼，才能讓別人有理由接受。
