這份年表整理本書討論的文本與成果，不替方法指定唯一出生日期。一本書的成書、抄本年代、翻譯、發表與後來的形式化，是不同事件。各列連回相關章節，原始來源、所讀版本與必要的年代限定都列在章末註記。

有些列用一段時期，有些列用確定的出版年。這不是精度不一致就必須補齊的空格；可用證據的精度本來就不同。特別是古代算法，現存材料能證明某時已有某種寫法，通常不能單憑它推定人類何時首次有了那個想法。

這份年表也不是把不同領域排成接棒賽。統計推論持續處理抽樣與模型的不確定，形式邏輯處理推導的條件，電腦驗證處理可檢查的形式物件；它們在時間上重疊，在問題上分工。

## 容易混淆的術語

| 術語 | 本書使用的意思 | 不宜直接等同 | 定義與展開 |
| --- | --- | --- | --- |
| 命題 | 可就其真假討論的明確陳述，須留意語境與量詞 | 一個關鍵字或含糊口號 | [第一章](ch01-why-prove.md)、[第八章](ch08-logic-and-foundations.md) |
| 證明 | 在明定前提與推理規則下，交代結論成立的理由 | 大量成功例子、作者信心 | [第一章](ch01-why-prove.md) |
| 證據 | 支持或反對一個主張的可檢查材料；效力依問題而異 | 無條件、不可修正的保證 | [第十一章](ch11-experiment-and-evidence.md) |
| 演算法 | 按明確規則執行的程序 | 程序正確性的證明 | [第二章](ch02-tablets-and-algorithms.md)、[第五章](ch05-algebra-and-symbols.md) |
| 公理 | 在所討論理論中作為起點接受的句子 | 不需說明適用對象的宇宙真理 | [第三章](ch03-greek-deduction.md)、[第八章](ch08-logic-and-foundations.md) |
| 模型 | 讓語言有解釋、並滿足指定公理的結構；科學模型另有應用意義 | 原對象的完整複製品 | [第七章](ch07-axioms-and-models.md)、[第十一章](ch11-experiment-and-evidence.md) |
| 相容性／一致性 | 在本書古典形式系統中，不會導出互相矛盾的句子 | 每條定理都符合預想的標準對象 | [第八章](ch08-logic-and-foundations.md)、[第九章](ch09-incompleteness-and-computation.md) |
| 健全性（邏輯） | 推理規則保存相應語義中的真；英文 soundness | 理論回答所有問題 | [第八章](ch08-logic-and-foundations.md) |
| 邏輯完備性 | 語義上由前提必然成立的句子，有形式推導 | 每個句子都由某個理論判為真或假 | [第八章](ch08-logic-and-foundations.md)、[第九章](ch09-incompleteness-and-computation.md) |
| 理論完備性 | 理論對每個句子能推出它或它的否定 | 單一命題已有完整、詳細的證明 | [第九章](ch09-incompleteness-and-computation.md) |
| 獨立性 | 特定理論既不能推出某句子，也不能推出其否定 | 任何理論都永遠無法處理 | [第七章](ch07-axioms-and-models.md)、[第九章](ch09-incompleteness-and-computation.md) |
| 可枚舉 | 程序可逐一列出所有合格項目 | 能對每個候選者有限時間內回答是或否 | [第九章](ch09-incompleteness-and-computation.md) |
| 可判定 | 有總會停止且正確回答指定判定問題的程序 | 算得快、成本可接受 | [第九章](ch09-incompleteness-and-computation.md) |
| 見證 | 滿足存在敘述的具體對象，並可檢查相應條件 | 只說「必定有」而未給出的對象 | [第十章](ch10-construction-and-programs.md) |
| 數學歸納 | 起點與歸納步配合自然數的結構 | 由許多觀察案例外推一般規律 | [第十章](ch10-construction-and-programs.md) |
| 經驗歸納 | 由觀察支持更廣的規律，效力依方法與假設 | 數學歸納法的另一個名字 | [第十一章](ch11-experiment-and-evidence.md) |
| 先驗／後驗 | 條件化前後，在指定模型中的機率分布 | 不可質疑的個人偏好／唯一客觀真值 | [第十二章](ch12-probability-and-statistics.md) |
| p 值 | 在虛無模型及其假設下，至少如此極端的指定統計結果之機率 | 虛無假設為真的機率 | [第十二章](ch12-probability-and-statistics.md) |
| 第一類錯誤 | 虛無假設為真時卻拒絕它 | 已發表結論為假的後驗機率 | [第十二章](ch12-probability-and-statistics.md) |
| 因果效應 | 對指定介入作比較的量，須明定對象、處置與結果 | 一張觀察表格上的組間差異 | [第十三章](ch13-causality-and-replication.md) |
| 可識別性 | 在模型假設下，目標量能由可觀察分布決定 | 已經有足量而乾淨的資料 | [第十三章](ch13-causality-and-replication.md) |
| 計算可再現性 | 按本書採用的用語，以相同資料與程序取得一致的計算結果 | 用新資料重做研究 | [第十三章](ch13-causality-and-replication.md) |
| 研究可重複性 | 按本書採用的用語，以新資料研究同一問題，結果在不確定性內相符 | 每個數字完全一樣 | [第十三章](ch13-causality-and-replication.md) |
| 證書 | 附在答案旁、可按規則核對的證據物件 | 對搜尋過程的全部紀錄 | [第十四章](ch14-computer-assisted-proofs.md) |
| 形式化 | 把對象、命題與理由放入明確的形式語言 | 自然語言的排版變整齊 | [第十五章](ch15-proof-assistants.md) |
| 可信核心 | 系統集中執行基本檢查規則的關鍵部分；仍須交代外部依賴 | 沒有假設、絕不可能出錯的裝置 | [第十五章](ch15-proof-assistants.md) |
| 形式化落差 | 原意、模型與實際形式陳述之間待核對的差別 | 核心判定器必然能自行修正的錯誤 | [第十五章](ch15-proof-assistants.md)、[第十七章](ch17-ai-and-proof.md) |
| 完備性（互動證明） | 真主張的誠實參與者按規則，應以協定規定的接受機率通過 | 一階邏輯的完備性 | [第十六章](ch16-interactive-and-zero-knowledge.md) |
| 健全性錯誤 | 在指定對手模型下，假主張仍被接受的機率上界 | 任何資料外洩的機率 | [第十六章](ch16-interactive-and-zero-knowledge.md) |
| 零知識 | 以模擬等定義刻畫，驗證互動不額外揭露所限制的資訊 | 沒有前提、完全沒有任何資訊傳遞 | [第十六章](ch16-interactive-and-zero-knowledge.md) |

「可靠性」與「健全性」在不同中文資料中也可能互換。讀英文 soundness 時，先看它是在談邏輯規則，還是在談互動協定的錯誤接受界限。詞典可以縮短查找，定義仍要回到正在使用的系統。

## 三條回讀路線

想再讀一遍歷史轉變，可以從第二至第七章開始，逐章記下理由以什麼形式保存：數字、程序、圖形、注釋、字母、極限與模型。每次只選一個具體例子重做，會比記住更多人名更容易看出方法的改變。

想理解電腦與 AI 的證明，可以依第八、九、十、十四、十五、十六、十七章的順序回讀。先分清語義與推導、判定與搜尋、存在與見證，後面的證書、核心與互動協定才不會變成只有名稱的工具。

想比較現實世界的主張，則從第一章接到第十一、十二、十三與十八章。試著替一份研究寫出主張、資料、模型假設與尚未回答的問題。這項練習不需要把每個日常判斷變成形式證明，但會讓不同種類的理由各就其位。
