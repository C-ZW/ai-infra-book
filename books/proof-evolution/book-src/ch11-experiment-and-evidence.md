# 第十一章　當答案必須問自然：實驗、測量與反駁

在一張紙上，兩條直線是否平行，可以依照選定的幾何公理討論。把同一個問題搬到地表上的測量，還要問尺怎麼放、光如何傳播、地面是否彎曲，以及儀器能分辨多小的差異。[第七章](ch07-axioms-and-models.md)讓我們看見公理可以有不同模型；自然界符合哪個模型，卻不能只靠在其中一個模型裡推導定理來回答。

科學推論仍然大量使用演繹。研究者從理論、初始條件和儀器假設，算出應該看見什麼，再讓觀察檢查這項預期。但測量結果不會自己附上一張「這就是世界唯一正確解釋」的證書。同樣的讀值可能符合多種模型，異常讀值也可能來自裝置。這一章要追蹤的，是人們如何把這些不確定因素拆開，使自然提供的反應能成為公開理由。

因此，證據與數學證明不能只按「強一點、弱一點」排成一條線。它們回答不同的問題。數學證明問結論是否由前提必然推出；經驗證據還要支撐前提與世界之間的連接。把後一種工作當成尚未做完的演繹，會低估實驗的難度；把它當成只能憑感覺，又會看不見儀器、比較與誤差分析如何提供約束。

## 一道移動的光紋要回答什麼

1887 年，麥可生與莫雷發表〈地球與發光以太的相對運動〉。他們把光分成沿兩條互相垂直路徑前進的部分，再讓光返回、會合，觀察明暗相間的干涉條紋。若兩條光路的相對行程發生微小變化，條紋位置便會改變。實驗要問的是：假定光相對一個靜止以太傳播，而地球上的裝置穿越以太，轉動裝置時是否會出現預期的方向差異？[^ch11-mm1887]

這個問題已經包含好幾項條件。「有以太」只是一個名稱，單靠這個名稱還算不出一個數。必須加上光相對以太的速度如何、裝置的運動如何影響光程、各臂的長度是否會因運動而改變，以及地球速度在儀器平面上的分量。還要有光學模型，將行程差換成條紋位移。測量看見的是條紋，理論真正受考驗的則是一組能推出條紋預期的假設。

以下用理想化的兩臂模型重建計算，展示預測如何產生，並非逐句轉寫原報告。設每條臂的單程長度為 L，光相對靜止以太的速度為 c，整個裝置沿其中一臂的方向以 v 移動，且 0 ≤ v < c。暫時不計材料收縮、折射率修正等因素。沿運動方向出去的光，必須追上前方的鏡子，因此相對接近速度是 c − v；回程迎向分光點，相對接近速度是 c + v。來回所需時間是 L/(c − v) + L/(c + v) = 2Lc/(c² − v²)。

垂直臂也不能直接寫成 2L/c。光往返的同時，鏡子正向側方移動；在以太的靜止座標中，光必須斜著走才會擊中鏡子。光速的側向分量要追上 v，剩下沿臂方向的分量才是 √(c² − v²)，所以來回時間為 2L/√(c² − v²)。這一步就是輔助模型的實際工作：一張標示「垂直」的儀器圖，不代表光在另一個座標系中也走垂直路線。

這裡要用一次近似，先交代省略了什麼。令 z = (v/c)²。沿運動方向的時間是 (2L/c)/(1 − z)；利用精確等式 1/(1 − z) = 1 + z + z²/(1 − z)，留下 1 + z，省略的是含 z² 的餘項。垂直方向則是 (2L/c)/√(1 − z)。設 s = √(1 − z)，直接通分可核對：

```text
1/√(1 − z) − 1 − z/2
= z²(s + 2) / [2s(1 + s)²],  s = √(1 − z).
```

當 0 ≤ z ≤ 1/2，s 不接近零，右邊小於等於 2z²。因此第二個近似留下 1 + z/2，省略的也受常數乘 z² 控制。換回速度比，保留的是 (v/c)²，省略的是 (v/c)⁴ 量級；這只處理這兩個時間式的代數近似，不會順便排除材料收縮等其他可能同階的物理效應。

當 v/c 很小，前者約為 (2L/c)(1 + v²/c²)，後者約為 (2L/c)(1 + v²/(2c²))。兩者相差約 Lv²/c³。把裝置轉九十度，兩條臂的角色交換，時間差改變約 2Lv²/c³。若波長為 λ，除以一個波長所對應的傳播時間 λ/c，就得到預期條紋位移約為 2(L/λ)(v/c)²。這是帶著小量近似的模型預測，所有省略項都須與欲測的精度相比較。

原報告給出的有效單程光程約十一公尺，相當於約二千萬個黃光波長；以地球公轉所對應的速度量級代入，預期轉動位移約為 0.4 條干涉條紋。[^ch11-mm1887] 用剛才的簡化模型，L/λ 約 2 × 10⁷、v/c 約 10⁻⁴，便得到 2 × 2 × 10⁷ × 10⁻⁸ = 0.4。這個數不是實驗者希望看見的裝飾，而是判斷裝置是否足夠敏感的工作目標。如果儀器只能分辨一整條條紋，沒有看見變化幾乎無法檢查這個預測。

## 實驗的精度藏在木蓋與水銀槽裡

原報告沒有只列一個最後答案。它說明，較早的實驗在轉動變形與振動上遇到困難；新的裝置把大石板放在浮於水銀上的支架，並以多次反射增加有效光程。光學部分加上木蓋，以減少氣流和快速溫度變化。[^ch11-mm1887] 這些安排讓同一個微小效應更容易觀察，也努力避免把轉動造成的機械變化誤認成光速的方向效應。

這裡有兩種相反的設計任務。一方面要放大預期訊號：光走得更遠，微小的傳播差異就能累積成較大的相位差。另一方面要抑制不需要的改變：鏡架若在轉動時受力、溫度若改變某條路徑，條紋也可能移動。靈敏度愈高，這些干擾不會自動變小。實驗者必須讓想問的問題變得看得見，同時辨認裝置自己說出的其他話。

把儀器調到有清晰條紋，也只是測量的起點。幾何尺規用來初步對齊光路，鏡子調整用來使兩束光會合，微尺讀值還要與條紋寬度對照，才知道一個刻度代表多少條紋位移。原文記錄這些調整與讀值的程序。[^ch11-mm1887] 對讀者而言，關鍵是原始數字與物理量之間有一條換算路徑；沒有這條路徑，「差了三格」既可能是強訊號，也可能只是一點不足以分辨的擾動。

現代測量學把這項責任分得很清楚：先定義待測量，再說明由哪些觀察與影響量推算它，最後交代結果的不確定度。誤差指測得值與待測量值之間的差異；不確定度則描述根據現有資訊，對測量結果仍有多大的分散或疑慮。兩者不能互換，因為真正的誤差通常無法確知。JCGM 的《測量不確定度表示指南》特別分開討論誤差、修正與不確定度。[^ch11-gum]

可以用一個虛構的尺規例子理解。假設某物長度實為一百毫米，一把尺的讀值固定多兩毫米，再疊加小幅擾動，三次讀成 101、102、103 毫米。平均為 102，重複得再整齊，也沒有消除共同的兩毫米偏差。若拿這把尺與一個有已知長度及不確定度的標準件比較，便能估計偏移並修正；但標準件自己的不確定度、溫度差與校正後漂移仍需計入。平均值不能代替校正。

同樣地，一個干涉儀若對微小鏡移完全沒有反應，就不能因為轉動時讀值穩定而宣稱理論受到了嚴格檢驗。研究者須確立儀器在相關尺度上會對已知改變作出反應。這不代表先知道待測答案；校正所問的是「儀器如何把改變轉成讀值」，正式實驗所問的是「在指定條件下，是否出現那項改變」。把兩個問題混成一個，便可能得到自我保證的測量。

## 零結果不是一張空白紙

1887 年的觀察沿圓周十六個方向讀值，裝置緩慢連續轉動，一圈約六分鐘，每組觀察連做六圈。作者指出，停下來逐點量會留下應變與溫度的影響，連續旋轉反而比較穩定。讀值在中午與傍晚等時段重做並列成表。[^ch11-mm1887] 這項安排把單一位置的「看起來沒有變化」，轉成可以比較的方向性紀錄。

轉動有特殊的邏輯作用。實驗沒有嘗試在兩個相隔很遠的地方用各自的鐘直接比較光速，而是用同一個裝置，讓兩臂相對於假定運動方向交換位置。如果理論預期的效應隨方向反轉，而某些干擾只帶來固定偏移，這種比較便能減弱後者的影響。但若某項機械擾動也隨轉動改變，它仍可能模仿訊號。實驗設計能分離部分來源，不能憑空保證所有來源都已消失。

作者最後判斷，與預期效應相應的實際位移確定不到預期的二十分之一，可能不到四十分之一。相對於 0.4 條條紋，這分別對應 0.02 與 0.01 條的尺度。[^ch11-mm1887] 這些是原報告的判斷用語，不能擅自翻成某個現代統計信心水準。結果給出的內容，是預期大小的方向效應沒有出現，並按當時裝置與判讀條件估計剩餘效應的尺度上限，而不是給出一個帶現代信賴水準的區間；它沒有建立「任意精度下都嚴格等於零」的數學定理。

若只記一句「沒有發現以太」，便會遺失大部分證據。沒有看見什麼，必須與本來有能力看見什麼配在一起。某台粗糙儀器看不到十分之一條紋，與另一台裝置能分辨更小尺度但仍未看到預期效應，對同一模型的壓力不同。可檢查的報告需要讓後來讀者重建這個比較，而不只要求相信作者眼睛很好。

數學也可能在實驗報告裡出錯。1887 年原文就回顧了較早計算忽略垂直光路效應的問題：修正後，原本應觀察的量只剩先前預期的一半，因此早期裝置能否分辨它，必須重新評估。[^ch11-mm1887] 這不是「實驗」與「理論」在兩個互不相干的房間工作。預測幅度算錯，會使對儀器的要求算錯，也會使對零結果的解釋過強。

## 一項反駁到底反駁了哪一部分

把理論核心記作 H，把光路、材料、速度與儀器等輔助假設合記作 A，預測記作 O。演繹結構是：H 與 A 一起推出 O。若可信的觀察與 O 不相容，便能推出 H 與 A 不能全部保持原樣。但單憑這一步，還無法指定錯的必定是 H。杜恒在 1906 年《物理理論：其目的與結構》中，明確討論了物理實驗檢查一整組理論承諾的問題。[^ch11-duhem]

這項分析很容易遭到兩種過度使用。有人認為，只要預測落空，就應立刻扔掉最醒目的理論名稱；他略去了儀器與輔助條件。也有人認為，既然總能懷疑某個輔助條件，任何結果都傷不到理論；他略去了那些輔助條件也可以接受別的檢查。真正的工作是找出可區分的後果：如果是材料變形，改換材料會如何？如果是溫度梯度，改變遮蔽、時間或位置會如何？修補假設要帶來新的責任。

莫雷與米勒在 1905 年的報告正提供這樣的材料。他們研究裝置尺寸是否可能因穿越以太的運動而改變，並製作可替換定距材料的裝置，試圖檢查材料性質是否影響結果。他們也記錄木製結構因乾燥而難以維持調整，後來採用更剛性的鋼架。[^ch11-mm1905] 這份工作仍有莫雷本人參與，因此不應誤標為與原團隊完全無關的獨立複核；它展示的是同一問題如何因新假設而要求新的裝置比較。

這份後續報告還檢查了地磁力會不會改變儀器。他們加上鐵塊、比較方向，並測試已知負重會讓條紋移動多少。[^ch11-mm1905] 這裡的負重試驗不是另一條關於以太的理論，而是在估量一個可能干擾需要多大的力才會造成讀值。若一項可疑來源在其他測試中被限制得很小，它就更難用來解釋原來欠缺的巨大效應。證據的約束來自不同檢查彼此接合。

另一方面，改變整個理論架構也可能帶來新的預測方式。愛因斯坦 1905 年的〈論動體的電動力學〉從相對性原理與光速條件出發，重新分析時間與座標；他在導言說明，在該理論中不必引入一個具有絕對靜止狀態的發光以太。[^ch11-einstein] 這裡只需注意方法上的差別：新的理論可以改變我們如何連接鐘、尺與運動，而不只是把某一台儀器的讀值改名。不能由一次零結果直接演繹出這整套理論，更不能把兩篇論文的時間先後當成思想影響的完整證據。

## 從看見現象到讓別人檢查

觀察、實驗、預測與解釋，在這個案例裡各有工作。觀察保存條紋在某時某方向的讀值；實驗主動改變方向或材料，使不同預期可以比較；模型預測把假設換成一個應有的幅度與變化形式；解釋推論則比較哪些假設能共同容納這些結果，以及它們付出了哪些額外承諾。沒有一張適合所有學科的步驟表，能把這些工作一次安排好。

天文學家無法隨意轉動一顆恆星，地質學家也無法重做整個地球的歷史，但仍能比較不同位置、不同儀器與不同現象的後果。實驗控制是一種有力的資源，並非唯一允許的證據形式。關鍵在於問題所需的區分能否由資料支撐：哪項觀察同時符合所有候選解釋，哪項觀察真的讓其中一些解釋承擔更難滿足的條件？「資料很多」與「資料有區分力」是不同的成就。

一個虛構的數值例子，可以精確展示資料如何限制解釋，卻沒有自動決定唯一解釋。暫時忽略測量誤差，假設在 x = 0、1、2 三個位置，得到 y = 1、3、5。直線 f(x) = 2x + 1 完全符合。但另一條曲線 g(x) = 2x + 1 + x(x − 1)(x − 2) 也完全符合，因為在三個已測位置，新增的乘積都有一個因子為零。

到了尚未測量的 x = 3，f 預測 7，g 卻預測 13。選擇這個位置的新觀察，便能區分原先被三筆資料一起保留下來的模型。這不是說實際物理研究只要任選多項式就行，而是顯示一個邏輯事實：有限資料吻合一條規則，通常也能吻合別的規則。若資料還帶誤差範圍，候選集合可能更寬。

我們會要求候選規則同時符合其他知識、遵守相關對稱或守恆關係，並承受新條件的檢查。因此，能硬湊三個點的曲線，不會只憑這項成功便與成熟理論取得同樣地位。解釋需要付出保持整體相容的代價。後來的測量也不只是增加一筆紀錄；選對位置，可以讓原先沒有區分力的比較變得有區分力。

這個例子同時提醒，對推論的可修正性保持清醒，不必導向「任何說法都一樣」。兩個模型若在相關條件下給出不同的數值，世界就有機會迫使我們改變其中一個。研究者要做的是把那個差別安排成可觀察的問題，並確保儀器誤差不會吞掉差別。選擇的新條件還須落在理論所承諾的適用範圍內，否則也許只發現了研究者從未宣稱過的外推限制。

這也使經驗歸納與[前章的數學歸納](ch10-construction-and-programs.md)清楚分開。觀察到若干次相似結果，可以支持對其他情境的期待，但那些情境是否仍符合原來條件，需要理由。數學歸納則已證明從任意自然數 n 到 n + 1 的推進規則。不能把反覆測量的穩定性寫成同樣形式，就以為跨到未測情境的責任消失了。

公開報告使這份責任離開單一實驗者。讀者可以檢查公式是否漏項，讀值換算是否一致，儀器究竟能看見多小的效應，也可以重建或改造裝置來問新的問題。公開沒有保證每個人都能立刻複製昂貴設備；它提供的是可以指認和接續的檢查路徑。若報告省略失敗的調整與干擾，後來的人也許會照著結論造出一台儀器，卻不知道真正左右結果的條件。

因此，實驗史裡的進步不只是更精密的數字，也包括更精密地交代「這個數字由什麼而來」。一項理論得到支持時，我們需要知道哪些替代可能受到了壓力；一項理論被質疑時，也需要知道哪段預測與觀察之間的連接承受不了。當剩餘的不確定無法靠增加刻度或換一塊材料完全消除，[機率與統計推論](ch12-probability-and-statistics.md)便把另一個問題放到桌面上：在明說模型與設計之後，這批有限資料究竟容許我們把話說到多強？
