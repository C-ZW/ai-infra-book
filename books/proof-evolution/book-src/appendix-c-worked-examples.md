# 附錄 C　算例與反例：把檢查做到最後

本附錄集中重算幾個跨章例子。數值是本書明定的教學條件；機率例子是模型推演，並非實測資料。可重跑的算術程式 `scripts/check-math.py` 與書稿一起提供，但程式檢查的是特定算例與一致性，不能代替一般定理的證明。

取得本書目錄後，用 Python 3.9 以上，在 `books/proof-evolution/` 執行：

```sh
python3 scripts/check-math.py
```

預期顯示 `PASS: nine canonical mathematical checks.`，以及九組算例的結果；加上 `--json` 可取得機器可讀輸出。不需安裝第三方套件。單檔 HTML 包含書稿，不內嵌這支 Python 程式；使用離線閱讀器的讀者須另從同一版儲存庫取得程式。

## 四十次成功：有限核對與下一個反例

[第一章](ch01-why-prove.md)使用 f(n) = n² + n + 41。n = 0 至 39 的四十個值均為質數；這是一項有限的算術事實，不是由「前幾項看起來是」來推定。逐一核對的方法是：對每個值 N，試除所有 2 ≤ d 且 d² ≤ N 的整數。若 N 有非平凡因數分解 N = ab，至少一個因數不大於 √N，否則兩者相乘會大於 N；因此這項有限檢查已涵蓋所有可能的合數情形。

n = 39 時得到 1601；再下一項 f(40) = 40² + 40 + 41 = 1681 = 41²，為合數。隨書程式既核對前四十項，也檢查這個反例，沒有把程式的有限成功外推成無窮命題。

同一式子在[第十七章](ch17-ai-and-proof.md)再次出現，用來問候選證明有沒有偷偷換題。兩章共用同一公式及 n = 40 的反例。

## 奇數和：五個例子與所有正整數

前五個正奇數是 1、3、5、7、9，總和為 25。若把這五項反過來再列一次，每一對加起來都是 10；五對合計 50，除以二得到 25。

一般地，對正整數 n，令 S = 1 + 3 + … + (2n − 1)。反向排列是 S = (2n − 1) + (2n − 3) + … + 1。同位置的兩項相加都等於 2n，一共 n 對，所以 2S = n × 2n = 2n²，得到 S = n²。關鍵是每一個 n 都有同樣的有限配對結構。[第一章](ch01-why-prove.md)與[第十章](ch10-construction-and-programs.md)分別從結構與歸納理解這種一般性。

算式裡的省略號不能自行承擔證明。我們已先明定第 j 項為 2j − 1，反向對應第 n + 1 − j 項；兩者和為 (2j − 1) + (2(n + 1 − j) − 1) = 2n。這把「每一對都一樣」展開成可逐步核對的理由。

## 乘積加一：新的質因數，不一定是新的質數

把 2、3、5、7、11、13 相乘，得到 30030，再加一得到 30031。然而 59 × 509 = 30031，所以 30031 是合數。這直接排除「一批質數相乘再加一，一定仍是質數」的說法。

它沒有推翻[第三章](ch03-greek-deduction.md)的無限質數論證。設有限清單為 p₁、…、p_k，令 N = p₁ × … × p_k + 1。對清單中任一 p_i，N 除以 p_i 都餘一，所以 p_i 不整除 N。又因 N > 1，N 有一個質因數 q。這個 q 不在清單裡，理由是清單上的任何數都不整除 N。證明只需要新的質因數，不需要 N 本身為質數。

在具體數字中，59 和 509 都不在原清單。因為 1 < 59 < 30031，而且 1 < 509 < 30031，59 × 509 已是一份非平凡因數分解，足以證明 30031 不是質數；無須先證 59、509 各自是質數。把「展示合數」與「完成質因數分解」分開，能避免多做的工作掩蓋真正所需的理由。

## 完成平方：題目範圍決定保留哪些解

考慮 x² + 10x = 39。兩邊加 25，得到 (x + 5)² = 64。在實數中，x + 5 = 8 或 x + 5 = −8，所以 x = 3 或 x = −13。

兩者都能代回：3² + 10 × 3 = 9 + 30 = 39；(−13)² + 10 × (−13) = 169 − 130 = 39。若 x 必須是一條正長度，就只保留 3；若題目詢問全部實數解，兩者都要列入。[第四章](ch04-plural-traditions.md)與[第五章](ch05-algebra-and-symbols.md)討論的是不同對象範圍如何改變這份答案。

同樣的符號也能暴露漏解。對 x² = x，若直接除以 x，得到 x = 1，便丟掉 x = 0。移項寫成 x(x − 1) = 0，利用實數沒有零因子的性質，才得到兩個解。代回一個解只證明它合格，不能證明沒有別的解。

## 近似平方根：先把真值夾住

[第二章](ch02-tablets-and-algorithms.md)先用容易重算的界線：1.414² = 1.999396 < 2，1.415² = 2.002225 > 2。正數平方保持大小順序，所以 1.414 < √2 < 1.415；以較小端點近似，誤差嚴格小於 0.001。把邊長乘三十，對角線的區間也乘三十，成為 42.42 至 42.45，寬度為 0.03。這是在放大誤差，不是運算出錯。

泥板數值的現代轉寫為 q = 30547/21600。精確平方得到：

```text
q² = 2 − 791/466560000
q < √2 < 2/q
2/q − q = 791/659815200 < 0.0000012
```

第一行的差是平方與二的差，不是 q 與 √2 的差。因 q 正且 q² < 2，q 是下界；又因 q < √2，2/q > 2/√2 = √2，所以 2/q 是上界。最後一行用兩界的距離保證長度誤差。小數只是顯示方式，保證來自分數不等式。

泥板轉寫和比例讀法見第二章的 Fowler／Robson 來源；上述分數差與界線是本書的現代重算，沒有宣稱原物上刻了這份誤差證明。

## 另一條近似路徑：平均為什麼會改善答案？

取一個高於 √2 的正數 u，令 v = 2/u，便有 uv = 2，且 v < √2 < u。把兩者平均，記成 m = (u + v)/2。直接乘開可得 m² − 2 = (u − v)²/4 ≥ 0，因此 m ≥ √2；另一方面 v < u，所以 m < u。新的上界更小，卻沒有降到 √2 以下。

從 u = 3/2 開始，v = 4/3，平均得 17/12。它的平方比二多 1/144。再把 17/12 與 24/17 平均，得 577/408，平方比二只多 1/166464。這裡證明的是每次有限更新的方向及這兩次計算，沒有把有限例子當成完整的收斂定理。

這些分數也不等於泥板的 30547/21600。數學上可行的算法，不能單憑結果相近就被認定是古人實際使用的方法。這段由原第二章移入，保留為另一份可逐步檢查的說明。

## 乘法完全正確，圓田面積仍可能只是近似

《萊因德數學紙草書》現代編號第五十題，用直徑九求圓田面積：先扣去直徑的九分之一，剩八，再算八乘八，得六十四。現存抄本屬公元前第二千紀，不應把抄本的年代直接當成方法的發明年代。[^apxc-rhind]

八乘八確實是六十四；這不能順便證明直徑九的圓和邊長八的正方形有相同面積。用今天的理想圓面積公式比較，π × 4.5² 約為 63.617，兩者相差約 0.383。算術步驟可以完全精確，把圓換成正方形的規則卻仍是近似。

原題的倍增記錄八、十六、三十二、六十四，讓後來的讀者看見部分中間運算。用本書另選的例子，十三乘十二也可拆成八份加四份：十三倍增成二十六、五十二、一百零四，取一百零四加五十二，得一百五十六。這組數不是紙草的原題；它只示範份數如何拆合，以及別人可以在哪一步檢查。

將原圓田規則寫成 (8d/9)²，是現代符號重寫。它相當於以 256/81 近似 π，不表示古代作者已用同樣的常數概念思考。單憑短短的程序，也不能確定他如何找到九分之八、是否認為它精確，或實際容許多少誤差。

## 基準率：分母不能只留下真正有特徵的對象

設 A 是一項假想特徵，+ 是檢查結果為陽性。本例明定 P(A) = 0.01、P(+ ∣ A) = 0.90、P(+ ∣ ¬A) = 0.05。假設模型適用，並且這兩個類別涵蓋整個母體，則對 10000 個對象可列出下表的期望數量。

| 真實狀態 | 陽性 + | 陰性 − | 合計 |
| --- | --- | --- | --- |
| 有 A | 90 | 10 | 100 |
| 無 A | 495 | 9405 | 9900 |
| 合計 | 585 | 9415 | 10000 |

要算 P(A ∣ +)，分母是全部陽性 585，分子是其中有 A 的 90。因此 P(A ∣ +) = 90/585 = 2/13 ≈ 0.153846，也就是約 15.38%。若用 90/100，算到的是 P(+ ∣ A)；兩者條件方向不同。

同一件事可直接寫成貝氏公式：

```text
P(A ∣ +)
= P(+ ∣ A)P(A) / P(+)
= (0.90 × 0.01) / (0.90 × 0.01 + 0.05 × 0.99)
= 0.009 / 0.0585
= 2/13
```

表格呈現的是給定比例下的期望數量，不保證任一隨機樣本恰好出現這些計數。改變母體比例、檢查模型或抽樣方式，都可能改變結果。這裡沒有提供任何現實個案的風險判斷；[第十二章](ch12-probability-and-statistics.md)用它澄清條件機率的方向。

## 多重檢定：每次五個百分點，並不等於整組五個百分點

假設二十個虛無假設全部為真，各檢定發生第一類錯誤的機率恰為 0.05，而且這二十個錯誤事件彼此獨立。每個檢定不誤拒的機率為 0.95，全部不誤拒的機率為 0.95²⁰ ≈ 0.3584859。取補事件，至少一次誤拒的機率為 1 − 0.95²⁰ ≈ 0.6415141，也就是約 64.15%。

這不是聲稱真實研究裡的每二十次檢定都具有相同風險。若事件相依，乘法公式不再由這些條件保證；若每個檢定沒有有效控制第一類錯誤，也不能任意填入 0.05。讀者應先看設計與假設，再決定哪個計算適用。[第十三章](ch13-causality-and-replication.md)把這項責任接到研究選擇與公開程序。

還有一個不需要獨立性的簡單上界：對任何二十個錯誤事件 E₁、…、E₂₀，P(至少一個發生) ≤ P(E₁) + … + P(E₂₀)。因為把各事件計數相加時，重疊部分可能被重複算，總和只會多算而不會漏算聯集。若每項機率至多 0.0025，總和至多 0.05。這是一個條件明確的數學界限，不保證某份資料分析已符合它的前提。

## 二十輪挑戰：小機率的保證也有精確範圍

在[第十六章](ch16-interactive-and-zero-knowledge.md)的理想化協定中，假設即使已知前面所有通訊紀錄，對一個假主張，作弊者在下一輪通過的條件機率仍至多 1/2。挑戰必須按協定新鮮產生，不能預先讓作弊者知道。

每多通過一輪，上界再除以二：一輪至多 1/2，兩輪至多 1/4，三輪至多 1/8。這不是假設整段作弊策略毫無關聯，而是每一步即使考慮先前紀錄，條件通過機率仍至多一半。

令 E_t 表示前 t 輪全部通過。只要 P(E_(t−1)) > 0，便有 P(E_t) = P(E_(t−1))P(第 t 輪通過 ∣ E_(t−1)) ≤ P(E_(t−1))/2；若前項為零，結論更直接成立。反覆使用這個條件上界，二十輪全部通過的機率至多 2⁻²⁰。

2²⁰ = 1048576，所以 2⁻²⁰ = 1/1048576 ≈ 0.0000009536743。換成百分比，要再乘 100，得到約 0.00009537%。「約百萬分之一」與「約百萬分之一個百分點」不同，單位不能省略。

這個上界只處理錯誤接受的機率。零知識、見證是否能被抽取、實作是否洩漏旁通道資訊，都不是由這個數字單獨證明。它們有各自的定義與論證責任。

## 四行表格與一份可檢查的矛盾證書

考慮四個子句同時為真：P ∨ Q、¬P ∨ Q、P ∨ ¬Q、¬P ∨ ¬Q，其中 P、Q 各只有真、假兩種值。

| P | Q | 為假的子句 |
| --- | --- | --- |
| 假 | 假 | P ∨ Q |
| 假 | 真 | P ∨ ¬Q |
| 真 | 假 | ¬P ∨ Q |
| 真 | 真 | ¬P ∨ ¬Q |

四種指定方式都至少使一個子句為假，且兩個二元變項恰有四種指定，所以無法同時滿足四個子句。這裡的窮舉是一份完整證明，因為我們交代了全部情況。

也可用較短的推理證書：由前兩個子句消去 P，得到 Q；由後兩個消去 P，得到 ¬Q；Q 與 ¬Q 衝突。驗證者只須檢查每一步消解是否符合規則，不必重新發現這條路。大規模證書仍需要可靠的規則與完整依賴；[第十四章](ch14-computer-assisted-proofs.md)說明這種分工如何延伸到人眼看不完的論證。
