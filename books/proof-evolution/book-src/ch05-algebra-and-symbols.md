# 第五章　字母接手圖形：代數、座標與一般性

在[上一章](ch04-plural-traditions.md)，一塊正方形加上幾塊長方形，讓 x² + 10x = 39 有了看得見的理由。把缺角補齊，得到 (x + 5)² = 64，再從邊長八減去五，答案是三。現在把圖收起來，只留下等式，事情立刻有了變化：x + 5 也可以等於 −8，於是 x 還可以是 −13。代入檢查，169 − 130 的確等於 39。圖形沒有畫出的答案，字母卻寫得出來。

這不是證明圖形有錯，也不能說古人漏算了另一半答案。如果 x 原本代表一條正長度，−13 根本不在問題准許的範圍內。若現在詢問所有實數解，問題已經擴大。符號讓這種擴大變得容易，也讓人更容易忘記自己何時改了題目。本章要追問的，正是符號的雙面能力：同一套寫法能保存一般理由，卻也可能把理由依賴的條件藏起來。

## 不只替未知數取名字

把未知量叫作某個名字，本身還不等於現代符號代數。比較「有一個數，加倍後再加六，等於二十」和 2x + 6 = 20，後者省了字，解題結構沒有根本改變。再把已知數也換成字母，寫成 ax + b = c，變化才更明顯。a、b、c 在每一道具體問題裡已經給定，卻不必先把數值填入，便能研究整類問題。它們是參數；x 是此時要尋找的未知量。

在 a ≠ 0 的條件下，先減去 b，再除以 a，得到 x = (c − b)/a。這一行容納了無數具體計算，但它的力量來自一個共同理由：實數的加法與乘法准許那些步驟，而且除數不是零。字母不是把很多答案塞進小盒子，而是把許多計算共用的依賴關係抽出來。若某一步用到 a 的非零性，這個條件必須跟著公式移動。

韋達在一五九一年的《分析術導論》中，把已知量和待求量一起納入字母運算；第五章第五條用母音與子音區分兩者。他同時要求同一等式中的量符合齊次性，也就是比較的量要有相容的量綱。這套寫法與今天的 ax² + bx + c = 0 並不完全相同；他的「平方」「立方」仍帶著當時對量的種類的理解。讀他的工作，應注意字母所承擔的職務，不能只看它們像不像課本上的字體。[^ch05-viete]

一般性的代價，也在 ax + b = c 裡完整顯露。當 a = 0，原式成為 b = c。若 b = c，每一個實數 x 都合乎要求；若 b ≠ c，則沒有解。把兩種情況塞進 (c − b)/a 都沒有意義。完善的解題程序必須先分支：檢查 a 是否為零，再決定要計算商、接受所有 x，或宣布無解。這個分支不是公式旁邊可有可無的小字；它是一般答案的一部分。讀者若只抄下最後那個商，便失去辨認輸入是否合格的能力。一項適用於整類問題的方法，應當把邊界情況也納入說明，不能讓公式最短的寫法決定問題的範圍。

這裡還有一個容易混淆的差別。「a 是任意給定的數」不是「同一道題裡，a 隨時可以變成另一個數」。一旦用某組 a、b、c 設題，推導途中就要維持同一組值。一般性來自理由不依賴某次特定選值，而非允許同一字母偷偷換身分。若前一行用 a 表示邊長，後一行又用 a 表示面積，運算也許仍像合法的代數，整段論證卻已中斷。

這使字母變成一種分工工具。一個人可以推導 ax + b = c 的通則，另一個人把特定題目整理成這種形式，第三個人執行數值計算。三人不必重做彼此全部工作，卻必須共享參數的意思與可用範圍。若第一人只保證 a ≠ 0，第二人就有責任查明自己的題目符合要求。縮短計算沒有縮短這條責任鏈，反而讓它更需要明文交接。

符號的外觀也不是一次決定的。雷科德在一五五七年的《智慧的磨刀石》裡，用一對等長平行線取代反覆書寫的「等於」，並交代這個記號的用意。這段文字留下的是一項可查證的印刷選擇，不足以替全世界的等式記法指定唯一源頭。[^ch05-recorde] 記號要成為共同語言，還得有人閱讀、使用、教學、重印。只要讀者尚未同意它代表什麼，再熟悉的形狀也不能自行保證推理。

## 一條等號，可能載著兩種承諾

等式變形常被教成移項、消去、開根號。這些名稱容易讓人以為，紙上每換一行，解答都會原封不動地跟過去。其實至少有兩種不同的承諾。一種是「原式成立，新式必定成立」；另一種還承諾反方向也成立。只有後者才保留全部且恰好的解。前者可以拿來尋找候選答案，卻不能免去最後的篩選。

考慮實數方程 √(x + 6) = x。這裡的 √ 表示非負的平方根，因此原式先要求 x + 6 ≥ 0，又因左邊非負而要求 x ≥ 0。平方兩邊得到 x + 6 = x²，整理成 (x − 3)(x + 2) = 0，所以候選值是 3 和 −2。代回原式，x = 3 時左邊 √9 = 3；x = −2 時左邊 √4 = 2，右邊卻是 −2。原方程恰有一個解，就是 3。

−2 從哪裡來？平方把正負差異抹掉了。若 u = v，當然有 u² = v²；但 u² = v² 只告訴我們 u = v 或 u = −v。原方程兩邊平方，擴大了可能符合要求的集合。若一開始把 x ≥ 0 保留下來，則在這個限制內，平方的反方向可以恢復：兩個非負實數平方相等，它們就相等。所謂增根，不是平方忽然失靈，而是我們把單向保證當成雙向保證。

這個差別值得寫成明確的閱讀習慣。當一份證明從 A 推到 B，應當問：作者只需要 A 成立時 B 成立，還是稍後打算拿 B 當作 A 的替身？前一種工作可能完全正確，後一種卻可能需要額外條件。求解通常關心兩個方向，因為既不能留下不合格的值，也不能丟掉原本合格的值。檢查幾個答案只能處理前一種風險，無法自動發現遺失的答案。

遺失答案的例子更短。由 x² = x 直接除以 x，得到 x = 1，代回原式也完全正確。然而 x = 0 同樣滿足原式，卻在除法那一步消失。正確處理是先分 x = 0 與 x ≠ 0，或移項得到 x(x − 1) = 0，再利用實數中兩數相乘為零必有一個因數為零，得出 x = 0 或 x = 1。證明「一是解」與證明「全部解只有一」，責任不同。

甚至可以用同一個漏洞假造荒謬結論。設 a = b = 1，由 a² = ab 可減去 b²，寫成 (a − b)(a + b) = b(a − b)。若消去 a − b，就得到 a + b = b，進而得到 2 = 1。錯誤發生在消去零因數，不在最後一行的算術。這種假證明有教學價值，因為每一步看起來都很熟悉；熟悉的動作越密集，隱藏條件越容易滑過眼睛。

平方根的例子還提醒我們，解方程與計算函數不是同一件事。y² = 9 的實數解是 3 和 −3；√9 則按本章的記號約定等於 3。柯西在一八二一年的《分析教程》預備篇，已仔細區分一般根的多個值與通常記號指定的值，並說明為何需要不同寫法。[^ch05-cauchy-roots] 這不是要求讀者背誦一份古老符號表，而是說明一項長久的責任：使用一個運算符號之前，必須知道它究竟回傳什麼。

## 公式何以成為整類問題的證明

回到二次方程，可以把完成平方從一張特定圖形提煉成共同程序。以下推導完全使用現代實數與記號，並非重現韋達的原頁。設 a、b、c 為實數，a ≠ 0，要求 ax² + bx + c = 0 的全部實數解。兩邊乘以非零的 4a，再移項及補上 b²，得到 (2ax + b)² = b² − 4ac。這些步驟都有反方向，因此原式與新式有完全相同的解。

令 D = b² − 4ac。若 D < 0，沒有實數的平方會等於 D，所以沒有實數解；若 D = 0，2ax + b = 0，只有 x = −b/(2a)；若 D > 0，則 2ax + b 分別等於 √D 與 −√D，得到 x = (−b + √D)/(2a) 或 x = (−b − √D)/(2a)。因為 2a ≠ 0，最後的除法合法；因為我們把平方的兩種可能都列出來，也沒有漏解。

這份證明同時給出一項演算法：檢查 a，計算 D，再按正負情況分支。可是「有演算法」和「有證明」仍然不同。演算法告訴執行者下一步做什麼；證明交代為什麼程序會停在符合題意的答案，以及為什麼不會漏掉別的答案。若有人只記得公式，卻把 a = 0 的輸入丟進去，程序就失去定義。若輸入是測量近似值，D 接近零時又另有數值誤差問題；精確代數證明並未自動替近似計算提供誤差保證。

把 a = 1、b = 10、c = −39 代入，D = 256，兩個實數解便是 (−10 + 16)/2 = 3 與 (−10 − 16)/2 = −13。這與開頭的完成平方相合。若題目還要求正長度，便在解出後與 x > 0 的條件取交集，只保留 3。符號的一般性沒有取消情境；它提供一個更大的候選空間，再要求我們明確指出情境取其中哪一部分。

另有一條從答案回看結構的路。若已知二次方程的兩個實數根是 r、s，且它可以寫成 a(x − r)(x − s) = 0，展開就得到 ax² − a(r + s)x + ars = 0。比較各次方的係數，可讀出 r + s = −b/a、rs = c/a。這裡的 r、s 不是兩個隨意挑選、碰巧通過測試的數；我們還用了原多項式確實具有這個分解的條件。若只代入兩個候選值而不交代次數與分解，就不能拿同樣理由宣稱任意方程只有兩個根。

在 x² + 10x − 39 中，3 與 −13 的和為 −10，積為 −39，恰好解釋因式 (x − 3)(x + 13) 的係數。這種讀法讓答案不再是一份孤立名單。和與積也許比每一個根更容易掌握，於是可以在尚未知道個別解之前，先限制它們共同具備的性質。符號的能力因而不只是把已知方法寫快一點；它讓「答案之間的關係」成為另一個可研究的對象。

擴大數的範圍，也不等於任何熟悉規則都能不加檢查地搬過去。歐拉的《代數原理》討論負數平方根時，指出這種根不能歸入正數或負數，因為兩者的平方都不為負。[^ch05-euler] 今天我們可以在複數中求 x² = −1 的解，但「每個數都有正負大小」這種實數直覺便不能照搬。擴充數系不是准許任意運算，而是同時改寫對象、規則與可提出的問題。這裡不需要學完複數，就能看見代數的一般教訓。

## 一個圓，兩個交點，兩次翻譯

笛卡兒一六三七年的《幾何學》，把線段的構造與算術操作緊密連在一起。第一卷先選一條線段作單位，再用比例構造乘法、除法與開平方；他也說明，標成平方或立方的式子，可以在選定單位後仍代表線段。因此，這本書不是先宣布「幾何從此消失」，而是設法在幾何構造與符號運算之間建立通路。[^ch05-descartes]

選單位這件事很容易被現代讀者略過。兩條長度相乘，依量綱通常得到面積；但若一條固定單位長度參與比例，就可以用一條線段表示乘積的數值。把長度三與長度四相乘得到數值十二，與聲稱長度等於面積，並不是同一件事。單位把數值與量連接起來。這也是為何公式移到另一種測量情境時，不能只檢查字母位置。

下面用現代直角座標做一個完整例子。選定平面上的原點、兩條互相垂直的軸，以及共同長度單位。點 (x, y) 的兩個數，是沿兩軸量出的有向位置。所謂有向，表示負號記錄方向，沒有把負長度當成實物。由直角三角形的畢氏關係，這個點到原點的距離平方為 x² + y²。因此半徑五的圓恰由滿足 x² + y² = 25 的所有實數座標組成。

「恰由」包含兩個方向。圓上的點距原點五，所以座標符合等式；反過來，若實數座標符合等式，距離是非負數，其平方為二十五，距離便是五，點就位於圓上。如果只證明第一個方向，等式仍可能描述比圓更大的圖形。代數化的可靠性，先取決於這次翻譯有沒有偷加或漏掉幾何條件。

現在尋找圓與直線 y = x + 1 的交點。交點必須同時滿足兩個等式。以 x + 1 取代圓方程中的 y，得到 x² + (x + 1)² = 25；展開是 2x² + 2x + 1 = 25；移項並除以二，得到 x² + x − 12 = 0；分解為 (x + 4)(x − 3) = 0。實數解為 x = −4 或 x = 3，從直線方程相應得到 y = −3 或 y = 4。

還要走回去。點 (−4, −3) 符合 −3 = −4 + 1，且 16 + 9 = 25；點 (3, 4) 符合 4 = 3 + 1，且 9 + 16 = 25，所以兩點確實都是交點。另一方面，任何交點都必須經過剛才的代入與分解，x 只能是那兩個值，而每一個 x 在直線上只對應一個 y。因此沒有第三個交點。答案不只是兩對座標；它包含存在與排除遺漏的兩份理由。

我們沒有用尺在圖上讀取 (3, 4)，也沒有把一張看似正確的圖當成普遍保證。可是幾何並未因此退出證明：選定直角座標、採用平面距離、把圓翻成等式，每一項都帶有幾何內容。若兩軸夾角不是直角，x² + y² 就不再是同一個距離公式。符號運算再完美，也無法補救起初翻錯的題目。

座標同時改變了可以有效提出的問題。沿著 y = x + c 移動直線，不必每次重畫一張完整構造；代入圓方程後，可以研究參數 c 如何影響解的個數。圖形仍能幫人猜想哪裡相切，代數則把猜想轉成可追蹤的條件。發現的路可能從圖到式，最後提交的證明卻可以先列條件，再按相反方向走。尋路順序不必等於交代理由的順序。

可以把這條參數線索推到底，看看一般理由如何超出一次求解。圓仍是 x² + y² = 25，直線改為 y = x + c，其中 c 是任意實數。代入後，方程成為 2x² + 2cx + c² = 25。完成平方得到 2(x + c/2)² = 25 − c²/2。左邊非負，因此若 c² > 50，沒有交點；若 c² = 50，平方只能為零，只有一個交點；若 c² < 50，平方等於正數，有正負兩種根，恰有兩個交點。這三種情況把所有實數 c 都涵蓋了。

這次甚至不必把兩個根展開寫出，便能證明交點數目。c = 1 對應剛才的兩個交點；c = 8 時，c² = 64 > 50，沒有交點。當 c = √50 時，唯一交點的 x = −c/2、y = c/2。把它代回圓，兩個平方之和是 c²/2 = 25；我們因此確認那條直線與圓相切。參數沒有增加含糊，反而把「移到哪裡會發生什麼」說得更準。

同一行完成平方還能直接讀成距離論證。直線上的任一點 (x, x + c)，到原點的距離平方為 2(x + c/2)² + c²/2。前一項至少是零，且在 x = −c/2 時確實等於零，所以直線到原點的最短距離是 √(c²/2)，也就是 ∣c∣/√2。最短距離大於、等於或小於半徑五，正好對應零個、一個或兩個交點。幾何語言中的「距離夠不夠近」，與代數語言中的「右邊能不能是平方」，在這裡彼此解釋。

注意這不是拿圖形的直覺替代代數證明。我們已證明那個最小值可達，也已由平方方程算出各種情況的解數；兩條說法因此能互相檢查。反過來，如果某次展開不慎把常數項寫錯，距離的解釋便可能暴露不合理之處。不同表達方式不必競爭誰比較高級。它們可以分擔發現錯誤的工作，只要各自與原題的連接都說得清楚。

## 簡短的式子，需要更清楚的讀者

今天讀歷史代數，很容易把自己熟悉的符號倒投到古書。這裡使用的笛卡兒法文數位本，底本是一八八六年的重排版；編者明說替換過部分記號，連等號也按後來習慣改寫。[^ch05-descartes] 同一個網頁上印著「笛卡兒」和 x²，並不能證明每一筆字形都出自一六三七年原版。作品的思想、當時的寫法與後世便於閱讀的重排，應當分開判斷。

這份警覺與解方程的警覺其實相通。重排者為了讓人容易讀，可能隱去舊符號；解題者為了讓人容易算，可能隱去分支。兩者未必有錯，問題是有沒有交代省略了什麼。符號最有用的時刻，是它讓許多人能沿同一條依賴關係檢查理由；最危險的時刻，是簡潔的外觀讓人誤以為不用再問範圍、單位與反方向。

所以，一份成熟的代數證明可以很短，卻不能只剩動作名稱。它要讓接手的人知道：字母可以代表哪些對象，這一步有沒有除以可能為零的量，開根號保留哪個值，算出的座標如何返回原題。當這些約定清楚，字母接手的就不只是圖形的外觀，而是跨越許多個案仍可共同檢查的理由。等到同樣的符號開始操縱「無限接近」與「無窮多項」，[下一章](ch06-infinity-and-limits.md)還會遇到另一種不能靠熟練手勢省略的條件。
