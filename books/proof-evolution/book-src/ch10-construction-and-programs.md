# 第十章　證明也能是一項構造：見證、直覺主義與程式

有時候，一個存在定理已經回答了問題。有人問某種安排是否可能，我們排除不可能的情形，證明答案為是，工作便完成了。另一些時候，提問者還在等下一步：既然安排存在，請把它交出來。這個要求沒有推翻先前的推理，卻改變了證明須提供的內容。一份理由可以保證有答案，也可以同時帶著找到答案的方法。

「見證」是滿足存在敘述的具體對象。要證明有整數 x 使 3x + 2 = 14，交出 x = 4，再核對等式，就交出了見證及其正確性證明。若定理的輸入會變，見證也必須隨輸入改變。這時一張孤立的答案紙不夠；我們希望有一個明確程序，接收每個合格輸入，最後產生符合要求的對象。

把證明與構造放在一起思考，在二十世紀的直覺主義與型別理論中取得了精細的形式，但建造對象本來就是數學的長期工作。[第四章](ch04-plural-traditions.md)的算法解釋、[第五章](ch05-algebra-and-symbols.md)的代數求解，都帶著這項責任。新的問題在於：能否把「有證明」的意義，系統性地連到「有可用的構造」？布勞威爾 1912 年的演講把數學對象的構造要求帶入基礎爭論；後來的研究則把這個方向發展成可檢查的推理語言。[^ch10-brouwer]

## 用平均值證明有一種好安排

考慮一個有限、無向、沒有自環的簡單圖。圖由一些頂點與連接不同頂點的邊組成，同一對頂點最多一條邊。把所有頂點分成左、右兩組，一條邊的兩端若在不同組，就稱它跨過這個「割」。問題是：是否總能找到一個割，使至少一半的邊跨組？這是精確的數學命題，不涉及對現實網路的抽樣推測。

設頂點有 n 個、邊有 m 條，n 與 m 都是非負整數。每個頂點可以標左或右，所以共有 2ⁿ 種標法。把這些標法等量看待，對任意一條固定的邊，它的兩個端點有左左、左右、右左、右右四種搭配，其中兩種跨組。其餘頂點如何安排，不影響這個計數。因此，在全部標法中，這條邊恰有一半的時候跨組。

現在把每種標法跨組的邊數加起來，再除以 2ⁿ，得到平均跨邊數。我們也可以換一個加總次序：先對每條邊，計算它在全部標法中貢獻了幾次。每條邊平均貢獻 1/2，m 條邊總共平均貢獻 m/2。至少一種標法的跨邊數不得小於 m/2；否則所有標法都低於這個數，它們的平均也必低於 m/2，矛盾。由於邊數是整數，m 為奇數時，保證還可以向上取到下一個整數。

這就是一個完整的存在證明。也可以用機率語言敘述它：每個頂點獨立且等機率地選左或右，跨邊數的期望值為 m/2。在這個有限模型中，期望值就是剛才的加權平均。我們沒有真的丟硬幣，也沒有觀察幾次成功便推測普遍定理。對所有可能標法的計算，已經保證存在性。艾狄胥 1947 年以計數全部可能圖的方式證明圖的存在，是這類思想在現代組合數學中的一項重要實例；這裡的割例子是為本章重新展開的初等論證。[^ch10-erdos]

用三角形就能看見平均值的作用。三個頂點有八種標法：全部在左或全部在右的兩種標法，各有零條跨邊；其餘六種標法，各有兩條跨邊。平均是 12/8 = 1.5，所以至少有一種標法達到兩條。三條邊不可能全跨組，因為兩個頂點若都和第三個分處兩組，它們彼此就會在同組。各邊是否跨組並不互相獨立；加總平均值的計算從未要求這種獨立性。

這份證明的結論也有明確邊界。它保證至少一半，沒有保證這個數就是最佳值，也沒有說任意一次隨機選擇都能達標。它在紙面上尚未替一個指定的大圖列出左右名單。這最後一項缺口，讓我們可以實際觀察：存在論證如何再長出一個構造。

## 把尚未作出的選擇逐一固定

最直接的方法是把 2ⁿ 種標法全部檢查一遍。圖有限，每種標法的跨邊數都可計算，而且剛才已證明有達標者，所以枚舉必定找到見證並結束。這點很重要：此例的平均值證明雖未展示見證，卻不代表結論在嚴格邏輯意義上毫無建構內容。「寫作時沒有給出答案」與「任何程序都不能給出答案」差得很遠。

還能做得更直接。先不固定任何頂點，所有標法的平均跨邊數是 m/2。選一個未固定的頂點，把剩餘標法分成兩群：它在左的一群，以及它在右的一群。兩群大小相同，所以兩群各自的平均值再取平均，等於原來的平均值。兩群之中至少一群的平均不低於原值。我們就固定這個頂點到那一邊，保留不會降低平均的選擇。

同樣的事可以一直做下去。每固定一個頂點，考慮範圍變小，但保留下來的平均跨邊數不減少。當 n 個頂點都已固定，範圍裡只剩一種標法。單一標法的平均就是它自己的跨邊數，因此最後得到的割至少有 m/2 條跨邊。這種方法常用「條件期望」來描述：每作一項選擇，就在剩餘可能性之中保留原有的平均保證。

我們還欠一個實作細節：選哪邊時，真的需要把剩餘標法全部算過嗎？不需要。對當前頂點，只計算它有多少鄰居已在左、多少已在右。把頂點放在左，便會跨過通往右側已固定鄰居的邊；放在右，則會跨過通往左側已固定鄰居的邊。選跨邊較多的一邊即可。通往尚未固定鄰居的邊仍有一半機會跨組，其他邊的貢獻不變，所以這項局部計數確實選到了平均較高或相等的一群。

例如在三角形中，先把 A 放左。B 的已固定鄰居 A 在左，所以把 B 放右。C 已有一個左鄰居、一個右鄰居，兩種選擇打平，任選一邊都得到兩條跨邊。這個程序的保證有兩部分：每步維持「剩餘平均至少 m/2」，以及每步少一個未固定頂點。前者說明品質，後者說明工作會完成。缺少任一項，還不能說已交出一個可靠的構造。

「能構造」也沒有自動附贈「算得快」。全部枚舉與逐點固定都會結束，但前者的候選數隨頂點數增加而倍增，後者只需逐點計算已固定鄰居的數量。證明兩者都能產生見證，屬於正確性問題；比較需要多少時間與空間，是進一步的成本問題。有時把一份存在證明拆開，最大的收穫正是看見哪些資訊其實不必搜尋。這裡沒有求出最大割，因而也不能把半數保證當成最優化問題已被完全解決。

## 歸納不是看了很多例子

剛才的程序反覆維持同一條性質。要證明它對任意大小的有限圖都有效，我們需要一種可以把有限步推理推到所有自然數的方法。數學歸納法的形式是：先證明 P(0)，再證明對每個自然數 n，只要 P(n) 成立，P(n + 1) 就成立，於是推出對所有自然數 n，P(n) 都成立。這裡自然數包含零；若問題從一開始，起點也可相應改成一。

第二步沒有預先假定「所有 n 都對」。它暫時接收某一個 n 的證明，展示如何產生下一個的證明。起點提供第一份證據，推進規則提供接續證據的方法。任何指定的自然數都能由有限次接續抵達，所以這個結構涵蓋每個自然數。型別理論把自然數的構造規則與歸納原理直接連在一起，馬丁－洛夫的講義對此給出明確的引入、消去與計算規則。[^ch10-martinlof]

看一個完整例子。定義 S(0) = 0，並令 S(n + 1) = S(n) + n + 1。這樣定義的 S(n)，就是從 1 到 n 的整數總和。要證明 S(n) = n(n + 1)/2。當 n = 0 時，兩邊都是零。假設某個 n 已滿足等式，則 S(n + 1) = n(n + 1)/2 + n + 1 = (n + 1)(n + 2)/2，正是下一個數所需的公式。基礎與推進都成立，定理便對全部自然數成立。

這與測量一百次後推測第一百零一次相同，有不同的理由。[下一章](ch11-experiment-and-evidence.md)的經驗歸納，要跨越已觀察與未觀察的世界；這裡的數學歸納，依靠已寫明的自然數結構和普遍的推進規則。若有人只檢查 n = 0 到 n = 100，卻未證明推進規則，就還沒有完成歸納證明。相反地，只寫出「若 P(n) 則 P(n + 1)」而沒有起點，也可能只建立一條永遠沒有啟動的接續鏈。

歸納法與遞迴在此相遇。遞迴定義把一個輸入的計算，交給較小輸入的計算；S(n + 1) 使用 S(n) 就是例子。從任意具體 n 開始，每次減一，最後抵達零，才能保證定義真的給出一個值。若寫成「S(n) 等於 S(n) 加一」，就沒有把問題交給較小的情形，也沒有得到可執行的解答。符號看似一個定義，不代表它已成功定義出對象。

自然數不能形成無限嚴格下降鏈，這是此處使用的「良基性」。要用遞迴交付答案，常須找出一個每次都嚴格下降的自然數量。割程序的量是尚未固定的頂點數；歐幾里得算法的量可以取下一輪的非負餘數。良基性使「重做一次」有終點。一般的樹或其他結構也可以有良基的較小關係，但必須說明那個關係，不能只用「看起來愈來愈簡單」取代證明。

例如求 35 與 22 的最大公因數，可以依序寫 35 = 22 + 13、22 = 13 + 9、13 = 9 + 4、9 = 2 × 4 + 1，最後 4 = 4 × 1。餘數持續下降且不能小於零，所以程序結束。把等式倒著代回，1 = 9 − 2 × 4 = 3 × 9 − 2 × 13 = 8 × 22 − 5 × 35。算法不僅說兩數互質，還交出整數見證 8 與 −5，讓讀者立即核對這項整數線性組合。

得到這份見證後，檢查者甚至不必重跑尋找它的算法：直接算 8 × 22 − 5 × 35 = 176 − 175 = 1 即可。任何同時整除 35 與 22 的正整數，都會整除這個線性組合，因而只能是一。發現答案的過程與接受答案的理由再次分開，但構造使那份容易檢查的理由得以交到別人手中。

在程式正確性研究裡，反覆成立的性質稱為不變量，保證終止的下降量常稱為變量函數或終止量。戴克斯特拉 1975 年的論文把不變量、下降條件與重複指令的正確性分開表達。[^ch10-dijkstra] 這個分工說明兩種常被混淆的承諾：「如果程式結束，結果會正確」以及「程式會結束，而且結果正確」。前一種承諾可以被一個永不結束的程式空泛地滿足；要交出見證，需要後一種。

## 排中律究竟少交了什麼

有限圖的例子可以枚舉，因此古典與建構式讀法在這裡很容易相遇。真正的基礎分歧出現在更廣泛的命題上。古典邏輯接受排中律 A ∨ ¬A：對每個命題，A 或其否定成立。直覺主義邏輯要求這種「或」的證明提供可使用的分支，因此不把任意 A ∨ ¬A 當成無條件通用原理。它仍允許在已知可判定的場合證明排中律，例如兩個給定整數是否相等。[^ch10-wadler]

以[第九章的停機問題](ch09-incompleteness-and-computation.md)來看，古典邏輯可以斷言：每個指定程式要麼停機，要麼不停機。但這句話沒有把一個總會結束的判定器交給我們。假如一項所謂構造，宣稱能接收任意程式，產生「會停」的分支或「不會停」的分支，而且分支總是正確，它就提供了前章已證明不可能的程序。古典的二分成立，與有效地選出分支，是兩種不同的內容。

也可以把這件事畫在無限二進位序列上。每一步先模擬某程式一步，尚未看見停機就寫零，看見停機後就寫一。古典上，這條序列或者全是零，或者某處出現一；但任何有限的零前綴都不能排除下一步才出現一。若一套有效方法能對這類序列總是選對分支，就能判定原程式停不停。這說明建構式要求的負擔不在於排斥大數或討厭無限，而在於分支必須由哪些資訊支持。

直覺主義也沒有一概禁止反證。若假設 A 會導致矛盾，就能建立 ¬A。受到限制的是把「假設 ¬A 導致矛盾」不加其他條件地轉成 A；前者直接給出 ¬¬A，從雙重否定取得 A，在一般情形需要古典原理。布勞威爾對集合間對應的討論已要求，某種存在敘述須交代有限步可完成的構造，而不能把無法判定的無限性質當成已經完成的選擇。[^ch10-brouwer] 這種要求改變了存在命題的使用方式，卻不必把古典數學描寫成一場錯誤。

## 一份證明可以有型別

命題與程序之間的對應，在「命題即型別」的思想中變得具體。型別可以先理解為一種物件所必須符合的規格；一個項屬於某型別，表示它具有這份規格所要求的形式。對適當的邏輯與計算系統，命題對應型別，證明對應具有該型別的項，整理證明的過程則對應計算。霍華德的〈公式作為型別的構造觀〉與馬丁－洛夫的型別理論，是這個方向的原始文本。[^ch10-howard][^ch10-martinlof]

假設已有 A 的證明 a，以及 B 的證明 b。要證明 A ∧ B，可以把它們合成一對 (a, b)；收到這一對時，也能取出第一份或第二份證明。因此，合取對應配對型別。要證明 A ⇒ B，則須提供一個方法：任何時候交給它 A 的證明，它都能產生 B 的證明。這就是一種函數型別。這裡的函數是把證據變成證據，並非把字串「A」改印成字串「B」。

試著證明 A ∧ B ⇒ B ∧ A。收到一對 (a, b)，取出兩個分量，交換順序，回傳 (b, a)。這個構造適用於任意 A、B，也不必知道兩個命題的具體內容。它的型別已記錄工作的形狀：輸入一份合取證明，輸出另一份合取證明。若從來沒有收到 A ∧ B 的證明，這份條件證明依然成立；它沒有無中生有地宣稱 A 或 B 已經為真。

同樣地，假設 f 把每份 A 的證據變成 B 的證據，g 把每份 B 的證據變成 C 的證據。我們便能構造「先用 f，再用 g」的方法：收到 a，就輸出 g(f(a))。這個短程序證明了從 A ⇒ B 與 B ⇒ C 可以得到 A ⇒ C。檢查者不必窮舉所有可能的 a；只需檢查中間結果的規格確實接得上。若 f 的輸出其實只承諾較弱的 B₀，g 卻要求完整的 B，這個接合就沒有根據。命題的精確文字，在程序裡成了不能略過的介面。

存在量詞可以帶著更多資料。要建立「有自然數 k 滿足 R(k)」，建構式的證據是一對：某個 k，以及 R(k) 的證明。第二份資料的規格依第一份 k 而變，這就是相依型別的一個入口。拿本章的割問題來說，輸出不只是一份左右標法，還要有它跨邊數至少為 m/2 的理由。實作時可以保存完整推導，也可能由另一個程序重新檢查這項性質；兩種安排對信任與成本的取捨，留待[第十五章](ch15-proof-assistants.md)討論。

這個對應不能直接套到所有日常程式語言。若語言容許任意遞迴，一段標註為「回傳某型別」的程式可能永遠不回傳。這樣的程式並沒有交出該型別的值。要把項視為邏輯證明，必須知道所用系統如何限制遞迴、保證計算規則的性質，以及允許哪些公理。加入古典原理後，命題仍可有形式證明，但未必都能抽出我們在這裡要求的直接見證程序。[^ch10-wadler]

還有一層界線不能由型別代勞。若把「左組至少有一個頂點」誤寫成規格，程式即使完美符合它，也不保證達到半數跨邊。規格必須先對上問題。證明、程式、見證三者可以互相提供新的檢查途徑，卻都需要有人說清楚輸入範圍與承諾。當一項存在定理被改造成可執行方法，我們增加的是能被傳遞、重做與使用的內容；這份內容愈清楚，下一位檢查者就愈能指出自己還在等待哪一項理由。
