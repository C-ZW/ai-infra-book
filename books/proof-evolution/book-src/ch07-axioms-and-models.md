# 第七章　可以換一套公理嗎：非歐幾何與模型

在紙上畫一條直線，再畫一個線外的點。經過這個點，似乎只有一條直線永遠不會碰到原來那條線。轉動尺，稍微偏離那個方向，交點就會出現在某處；角度越小，交點越遠。這幅圖讓「只有一條」非常可信，卻沒有替「永遠」完成證明。紙張再大，也只顯示有限的一段。

若把這件事當作公理，便准許後面的證明使用它。若想把它改列為定理，就必須從已經接受的其他條件推出來。兩種安排可以使用同一幅圖，卻承擔不同的責任。公理化所問的不只是某個說法是否直觀，也包括：這個說法究竟從哪裡獲得保證？本章要追蹤的改變，正是人們開始用一個幾何世界，檢查另一套幾何主張的依賴關係。

## 一條畫不完的線，與一個證不出的要求

歐幾里得第五公設的原文形式，比「過線外一點恰有一條平行線」複雜。它談一條直線截另外兩條直線：如果同側內角之和小於兩個直角，那兩條線向該側延長便會相交。相交發生多遠，公設沒有設上限。熟悉的唯一平行線說法，在適當的其他幾何公理下與它等價；不能省略這個背景，直接把兩句話當作逐字相同。[^ch07-euclid]

「其他公理」也需要一份明確名單。[第三章](ch03-greek-deduction.md)已經看到，《幾何原本》的論證依賴圖形、構造及共享的閱讀習慣。到了研究某條公理是否獨立時，這些習慣可能偷偷帶回答案。例如，用「兩條等距直線」解釋平行，再不加證明地認定它們必定存在，就可能把需要證明的性質藏進定義。

這不表示每次使用圖形都不可靠。問題在於，原本足以協助理解一個定理的背景，未必足以判定一個公理不可省。要主張「我沒有用到平行公設」，必須能指出所有已用的前提。若論證某處使用了等價於平行公設的命題，換一個名稱不會減少依賴。

羅巴切夫斯基在一八四〇年的《平行線理論的幾何研究》中，發展了不同的平行線理論。其第十六節區分相交方向與不相交方向，並以它們的界限說明平行線。這已把工作從「設法消除這個選項」轉向「看看這個選項能支持什麼」。本文所參照的是霍爾斯特德一八九一年的英譯，年代不能與德文原作混用。[^ch07-lobachevsky]

然而，推導出許多彼此相容的定理，還不是保證整套理論永不矛盾。也許矛盾只是躲在很長的證明後面。反過來，持續找不到一條證明，也不表示那條證明不存在。要回答這兩種困難，需要一種能把「所有可能的推導」一併管住的方法。

## 模型把抽象條件變成可核對的對象

先把「模型」理解成一份有內容的解釋：指定哪些東西算點，哪些東西算線，何謂在線上、介於兩點之間，以及何謂兩段同長，再檢查這些解釋是否滿足列出的公理。一幅看起來像某個空間的畫，不會因此自動成為模型。它必須讓每個關係都有明確含義，讓每條公理都有可檢查的真值。

希爾伯特的《幾何基礎》初版於一八九九年，按不同類別安排點、線、面及它們的關係。他不要求一開始就用物質或感覺給「點」一個最終定義；研究的中心是這些對象共同遵守的條件。這使同一套條件可以接受不同解釋，也使缺少哪一類條件造成什麼差異，成為可分開研究的問題。[^ch07-hilbert]

這種做法並不等於隨意改名。如果宣稱某些對象是某套公理的模型，卻找不到通過兩個不同點的唯一一條線，而公理明明要求它存在且唯一，那份宣稱就是錯的。自由在於可以尋找新的解釋；約束在於必須履行全部已列出的承諾。

我們在通常的實數座標平面裡，選出開單位圓盤 D：

D = {(x, y)：x² + y² < 1}。

現在約定，模型中的點就是 D 內的點。模型中的一條直線，是通常平面的一條直線留在 D 內的全部部分，也就是一條不含兩端的弦。圓周不屬於這個世界；圓外的點也不屬於。這些約定是圓盤模型的點與線部分，接下來的計算先檢查它們的交會性質。

兩個不同的圓盤內點，仍決定唯一一條模型直線。因為在作為背景的通常平面裡，它們決定唯一一條直線；取那條直線與 D 的交集，就得到所要的弦。若有另一條模型直線經過同樣兩點，它所屬的通常直線也經過同樣兩點，因而必須與第一條重合。

圓盤也不會把連接內部兩點的線段從中切斷。設兩點的位置向量為 U、V，t 介於零與一，線段上的點可寫為 (1 − t)U + tV。其到圓心距離的平方等於

(1 − t)‖U‖² + t‖V‖² − t(1 − t)‖U − V‖²。

這裡 ‖U‖ 表示 U 到圓心的通常距離。減去的 t(1 − t)‖U − V‖² 非負，而前兩項之和是兩個小於一的數的加權平均，所以整式小於一。整條線段都留在 D 內。「中間的點還在這個世界」在這裡有了代數理由，不只靠圓盤看起來沒有缺口。

## 一個點可以有多少條不相交的線

取模型直線 ℓ 為水平直徑，也就是 y = 0 且 −1 < x < 1 的部分。再取線外的模型點 P = (0, 1/2)。通常平面裡通過 P 的每條非鉛直直線，可寫成

y = mx + 1/2，

其中 m 是斜率。每個實數 m 都給出一條經過 P 的模型直線。我們不必靠把圖越畫越大，便能查明哪些線與 ℓ 相交。

當 m = 0，兩條通常直線就是不同的水平線，當然沒有交點。當 m ≠ 0，要與 y = 0 相交，必須有

0 = mx + 1/2，因此 x = −1/(2m)。

這是通常平面裡唯一可能的交點。但它是模型中的交點，還必須通過另一項檢查：點 (x, 0) 必須位於圓盤內，亦即 |x| < 1。代入後，條件成為

1/(2|m|) < 1，也就是 |m| > 1/2。

於是，|m| > 1/2 時交點在圓盤內；|m| = 1/2 時交點落在被排除的圓周上；0 < |m| < 1/2 時交點在圓外。加上 m = 0 的情形，所有滿足 |m| ≤ 1/2 的斜率，都產生與 ℓ 不相交的模型直線。

| 斜率 m | 通常平面的交點 | 是否是模型中的交點 |
| --- | --- | --- |
| 0 | 沒有交點 | 否 |
| 1/4 | (−2, 0) | 否，位於圓外 |
| 1/2 | (−1, 0) | 否，位於圓周 |
| 1 | (−1/2, 0) | 是，位於圓盤內 |

這些不是同一條線換了寫法。例如 m = 0 的線包含 (1/4, 1/2)，m = 1/4 的線在 x = 1/4 時卻有 y = 9/16。不同斜率確實產生不同的弦。只要在區間 [−1/2, 1/2] 任選斜率，就有一條通過 P 而與 ℓ 不相交的線；這樣的選擇有無限多個。

不相交的原因也有兩種面貌。斜率 ±1/2 的兩條線，恰好把相交方向與不相交方向隔開；其通常延長線在 ℓ 的圓周端點相遇。區間內部的斜率則沒有這個性質。在雙曲幾何的某些術語中，「平行」專指前一種界限情況，其餘叫超平行。為免把名稱當成結論，本章的計算始終說「不相交」。羅巴切夫斯基原文對平行的界限式定義，也提醒我們不要把現代教科書裡不同的用語混成一種。[^ch07-lobachevsky]

如果有人說兩條弦「其實在圓外相交」，他對通常平面說了一件真事，卻還沒有反駁模型內的結論。模型只讓 D 內的點參與「存在一個交點」這句話。當我們研究一個國家境內兩條道路是否交會時，境外的交會不能自動回答境內的問題；幾何模型則把這種範圍限制做成了精確的定義。

但這也正是容易說得太快的地方。只把平面裁成圓盤，並不能保證它已符合所需的全部幾何公理。若繼續把尺上通常的距離當成模型距離，靠近圓周的點便可能沒有空間再放下一段指定長度的線段。若把紙上的角度直接當成模型角度，也可能錯判全等。點與線的交會只是第一批檢查，長度、角度與連續性還有各自的工作。

希爾伯特在討論平行公理的獨立性時，除了把對象限制在球內，也重新指定全等關係，使用保持邊界的變換；這個構造在平面上對應弦式圓盤模型。完整結論依賴這些額外定義與公理驗證。本節已完整證明圓盤內的交點分類，並未把它冒充為整套雙曲幾何模型的完整驗證。[^ch07-hilbert]

還可以從相反方向檢查圖像的可靠性。把通常平面的一個點 X，送到圓盤內的點 F(X) = X/(1 + ‖X‖)。原點仍送到原點；距離原點 r 的點，送到同方向距離 r/(1 + r) 的點，這個距離永遠小於一。反過來，圓盤內的點 V 可還原成 V/(1 − ‖V‖)。每個點都能唯一往返，所以這是一個把整個平面裝進圓盤的一對一對應。

如果我們把通常直線的整個影像叫作新直線，把原本的距離也透過這個往返對應搬過去，得到的仍是歐氏幾何。兩條新直線是否相交，只取決於搬動以前是否相交；過線外一點的唯一平行線也會完整保留。這些新直線一般不會是前面指定的弦，雖然所有圖案都放在同一個圓盤裡。

這個對照有實際的判別力：畫面有圓形邊界，不能單獨說明內部空間是有限、雙曲或歐氏。決定答案的是對象與關係如何定義。前面的弦模型改變了哪些點准許成為交點；這個搬運模型則連同原來的交會關係一起保存。兩種構造都可以在紙上完成，但不能因為外形相似就交換它們的定理。模型的名字也不能代替那份逐條可查的定義。

## 球面能提醒什麼，又不能證明什麼

另一種很有力的圖像來自球面。把一顆理想球的北極記作 N，赤道上經度相差九十度的兩點記作 A、B。沿兩條子午線從 N 分別走到 A、B，再沿赤道的短弧從 A 走到 B，便圍出一個球面三角形。這三條邊都是大圓弧：所屬圓的圓心就是球心。

在 A 和 B，子午線與赤道垂直，所以各有一個直角。在 N，兩條子午線的夾角等於所選的經度差，也是九十度。因此三個內角加起來是二百七十度。這不是量角器誤差；把球與大圓設為理想數學對象後，三個直角由對稱與垂直關係精確決定。

此例揭露「三角形內角和是一百八十度」需要交代三角形所在的幾何與邊的含義。可是，不能由此宣布球面滿足歐幾里得其他公理，只違反平行公設。球面上兩個相對的點，例如南極與北極，位於無限多個大圓上；兩點決定唯一一條線的條件已經失效。兩個不同大圓還會在一對相對點相交，與通常直線的交會規則也不同。

貝爾特拉米一八六八年的〈非歐幾何解釋試論〉，在研究曲面上的幾何類比時，就明確指出球面對徑點不能唯一決定大圓這個例外。模型工作的細緻處，正是在誘人的類比裡找出不能一起搬過去的條件。若目的是證明某條公理獨立，任何額外失效的公理都必須納入考慮，不能因為圖像有說服力便略去。[^ch07-beltrami]

球面比較仍有價值。它讓人看出，幾何性質取決於哪些曲線被當作直線、哪些距離被當作距離，也迫使我們區分局部與整體。球面上一小片區域可以很像平面，卻不能因此推出繞完整顆球仍有相同的全域性質。直覺在這裡提供新的問題；模型驗證決定它能支持多強的結論。

## 用一個世界替另一個世界承擔多少風險

現在回到「平行公理能不能從其他公理證出」的問題。先固定一套明確的背景公理，包含所需的關聯、順序、全等等條件，卻暫不加入平行公理。把這套共同條件叫作 N；不同版本的中性幾何會有不同的精確安排，因此 N 不是一份可以任意省略的空白名單。

接下來是一個有明確前提的推論，不是宣稱前面那張圓盤圖已完成全部模型驗證。前文只檢查了點、弦與相交關係；完整的雙曲模型還要讓 N 中的順序、全等與其他公理全部成立。這項完整模型成果在本章是引用的背景結果，而不是剛才那個局部例子的結論。

假設我們已在同一套背景數學中，建立兩個滿足 N 的完整模型。一個是通常的歐氏平面，唯一平行線條件成立；另一個是完整指定的雙曲模型，唯一平行線條件不成立。假如存在一份只使用 N 的合法證明，推得唯一平行線條件，那份證明的每一步也必須適用於第二個模型。但它的結論在第二個模型為假，這與推理規則保存真理的要求衝突。因此不能存在那樣的證明。

同樣地，第一個模型阻止我們只從 N 證出唯一平行線條件的否定。兩個方向合起來，才得到該條件相對 N 的獨立性。本段證明的是「如果這兩個完整模型已建立，獨立性便跟著成立」；它示範模型怎樣阻止一份證明，沒有把完整雙曲模型的建構與逐條公理驗證也算成本章已完成的工作。關鍵不在「大家試了很久都失敗」，而在一份假想的成功證明，不論多長，都必須同時適用於滿足相同前提的模型。

這裡說模型為什麼能成立，又使用了實數、集合、座標計算等背景。若把非歐幾何的點解釋成實數對，把線解釋成某些實數對的集合，非歐幾何中的矛盾便會經過翻譯，成為背景數學中的矛盾。所以模型提供的典型保證是相對一致性：如果背景理論一致，所解釋的理論也一致。它沒有憑空給背景理論一張永不出錯的證書。

希爾伯特在《幾何基礎》第九節構造座標解釋時，明說幾何公理系統若導出矛盾，相關的數的算術裡也會出現矛盾。這段文字的分量在於交代責任轉移的方向。說「模型證明了無矛盾」若刪掉所依靠的背景，會把一個有條件而強大的結果誇成無條件的保證。[^ch07-hilbert]

獨立與一致也不是同一件事。「獨立」問某一條主張是否由指定前提決定；「一致」問整套前提會不會容許推出互相否定的主張。一個模型可能協助回答兩個問題，但兩個答案需要不同的比較。只找到通常平面，足以支持那一種解釋，卻還沒有排除平行公理可能由其他公理推出；還得有滿足共同前提而使它失敗的另一個模型。

## 哪一個空間是我們所在的空間

黎曼一八五四年的就職演講，後於一八六八年刊行，把可考慮的空間與度量關係推得更廣。他區分空間的延展關係與測量關係，並追問後者的假設在什麼程度上得到經驗支持。所閱克利福德英譯刊於一八七三年；它不是演講當年的英文紀錄。[^ch07-riemann]

這種區分讓數學問題與物理問題各自變得更精確。數學家可以問：假定某套距離與幾何條件，三角形角和應該如何變化？物理研究者則要問：我們用來量距離的尺、用來定方向的光、用來比較角度的儀器，在實際條件下符合哪一套模型？後一個問題需要觀測，也需要說明儀器如何代表數學對象。

用真實地球上的航線介紹球面三角形很方便，但地球不是完美的數學球，路線也不會自動等於理想大圓。理想球上的二百七十度有演繹保證；某次實測的三個角有多接近這個值，還受模型與測量條件支配。[第十一章](ch11-experiment-and-evidence.md)將把這種連接自然與理論的理由另外展開。證明某個模型自洽，不能單獨證明自然選擇了它。

公理因此不必只被理解為任何人都不得懷疑的顯然真理。它也可以明確標示一項研究承諾：先接受哪些條件，探索它們共同支持哪些結果，再比較不同承諾之間的關係。一旦能這樣做，曾經令人焦躁的「為何這一條始終證不出來」，便能轉成有內容的數學結論。

不過，這整個論證依賴一句還沒有仔細拆開的話：合法推理會保存模型中的真。究竟哪些符號組成命題，什麼算一步合法推理，模型又怎樣使一句話為真？當我們用模型約束所有可能的證明時，證明本身也進入了需要精確描述的對象之列。下一章將從這裡繼續。

[^ch07-lobachevsky]: Nikolai Lobachevsky，《Geometrische Untersuchungen zur Theorie der Parallellinien》，1840；George Bruce Halsted 英譯《Geometrical Researches on the Theory of Parallels》，1891，第 16 節。[版本與全文](https://archive.org/details/geometricalresea00loba)；[可檢索原書 OCR](https://archive.org/stream/geometricalresea00loba/geometricalresea00loba_djvu.txt)。支持相交／不相交方向及界限式平行定義；本章的座標斜率計算為自行構造，未歸給原作者。
[^ch07-hilbert]: David Hilbert，《Grundlagen der Geometrie》，初版 1899；E. J. Townsend 英譯《The Foundations of Geometry》，1902，參照 1950 重印本，第 1、9、10 節。[Project Gutenberg 原書 PDF](https://www.gutenberg.org/files/17384/17384-pdf.pdf)。支持按公理類別分析關係、以算術解釋幾何的相對一致性，以及限制在球內並重定全等的平行公理獨立性構造。正文只逐項證明平面圓盤的指定交會性質，完整模型驗證仍以原書條件為準。
[^ch07-beltrami]: Eugenio Beltrami，〈Saggio di interpretazione della geometria non euclidea〉，《Giornale di Matematiche》，卷 VI，1868，正文開頭關於曲面、測地線及球面例外的討論。[原文校讀本](https://it.wikisource.org/wiki/Saggio_di_interpretazione_della_geometria_non_euclidea/Saggio)。支持幾何解釋的方法與對徑點不能唯一決定大圓的明確限制；不將球面當成只違反平行公設的模型。
[^ch07-riemann]: Bernhard Riemann，〈Über die Hypothesen, welche der Geometrie zu Grunde liegen〉，1854 年演講，1868 年刊行；William Kingdon Clifford 英譯〈On the Hypotheses which lie at the Bases of Geometry〉，《Nature》，1873，第三部分第 2–3 節。[版本資料](https://www.maths.tcd.ie/EMIS/classics/Riemann/index.html)；[英譯全文](https://www.maths.tcd.ie/EMIS/classics/Riemann/WKCGeom.pdf)。支持區分延展與度量關係，以及幾何假設對實際空間的適用需要經驗研究；正文沒有把後來的物理理論倒放進這篇演講。
