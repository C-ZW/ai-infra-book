# Independent editorial review records

These six reports cover eighteen chapters and four appendices. Reviewers authored different chapters from those they reviewed, but used the same model family. This is not cross-model certification. The preface was prepared by the root editor and is not counted as an independently reviewed chapter.

`index.json` maps each final source file to its report, reviewer and SHA-256. The root editor compared every final digest with the actual source before packaging. Reports retain initial observations and corrected passages; when both initial and final hashes occur, the index identifies the accepted final version.

The detailed schemas differ because each reviewer recorded the actual checks needed for that batch. A direct-source support label establishes the stated, scoped support. It does not automatically satisfy the legacy template's stronger requirement for two independent primary origins. Reprints, translations and mirrors are not counted as new originating evidence.

Conversation-only tool reference IDs and absolute workspace prefixes were removed or normalized during export. Source URLs, retrieval scope, mathematics, findings and limitations remain. The records report completed review work; they do not guarantee that no further error can ever be found.

See `../verification-report.md` for the combined outcome and `../verify-log.md` for the editorial decisions.
