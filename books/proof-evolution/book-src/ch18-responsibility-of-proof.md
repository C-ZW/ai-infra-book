# 第十八章　什麼理由值得接受：把證明的責任交代清楚

設想一場討論，桌上擺著四份文件：一個數學命題的證明、一張模擬圖、一項教學研究的報告，以及 AI 產生的形式驗證結果。四位提出者都說，自己的結論「已經證明」。如果只問哪份文件最可靠，很容易把問題問錯。每份文件先得說清楚自己擔保什麼，反對者才知道該查哪裡。這些都是本章的假想案例，目的是追究同一件事：當一個結論要求別人據以思考或行動，提出者究竟欠對方哪些理由？

本章主張，值得接受的理由，應當讓責任可以定位。若問題出在推導，能指出哪個步驟需要補足；若問題出在模型，能說明哪項假設尚未連到現實；若需要依靠專業分工，能找出誰檢查了哪一部分。責任可以交給不同的人與工具，卻不能在交接時消失。這項要求比「大家都親自重做一次」可行，也比「相信專家就好」具體。

## 一個反例究竟推翻了哪句話

先看數學文件。它寫著 1 + 3 + 5 + 7 + 9 = 25，接著宣稱前 n 個正奇數的和等於 n²，其中 n 為正整數。反對者說，只算五項不能保證所有 n。這個反對成立，但成立的對象是那份理由的充分性，還不是一般命題的真假。提出者可以補上[第一章](ch01-why-prove.md)的結構論證，讓讀者看見增加一項與正方形擴大的關係；也可以選擇另一個完整證明。此時應修補的是從例子到一般性的缺口。

假若反對者接著堅持，沒有親眼看過任意大的正方形，就不能接受公式，要求又走過頭了。證明中的 n 不是某個等待畫出的巨大圖形，而是任意正整數。只要通用步驟沒有依賴未說出的大小限制，有限文字便能處理無限多個 n。合理的疑問應追問一般步驟是否有效；要求逐例看完所有整數，會把數學證明改成一項永遠做不完的觀察。

另一份稿子聲稱，把一串質數相乘再加一，結果必定是新的質數。現在反對者提出 2 × 3 × 5 × 7 × 11 × 13 + 1 = 30031 = 59 × 509。這次反例直接否定了「結果必定是質數」。然而它沒有否定質數無窮多。[第三章](ch03-greek-deduction.md)的理由只需要乘積加一之後，存在不在原清單中的質因數；歐幾里得《幾何原本》IX.20 的論證也區分所構造數為質數或非質數的情形。[^ch18-euclid]

這個區分影響批評的品質。指出一個錯誤步驟，足以要求撤回該步驟，卻未必足以撤回所有依靠相近想法的結論。相反地，結論另外有正確證明，也不能替眼前的錯誤推導洗掉缺陷。若把討論變成「支持或反對某位作者」，這兩種錯誤都容易發生。把每項異議對準明確陳述，才能保留成立的部分，也能準確修理失敗的部分。

這裡也有提出者的義務：不能在受到批評後，悄悄把「結果是質數」改成「結果有新的質因數」，然後宣稱自己從未出錯。後一句可能正確，但修改應該留下可見紀錄。讀者需要知道，先前引述的究竟是哪個版本，哪些後續推論要重查。證明具有可修正的文本歷史，並不使正確性變成任意；它讓錯誤修正有可追查的位置。

## 模擬圖之外，還缺哪一段理由

第二份文件來自一個假想的數值模型。每一步以 x_t 表示狀態，以 u_t 表示外部輸入，t 為含零的非負整數。更新規則是 x_(t+1) = (x_t + u_t)／2，作者宣稱狀態永遠落在 0 與 1 之間。模擬圖畫了許多條平穩曲線，但圖本身沒有說明初值與所有未畫出的輸入序列。反對者真正需要問的是：這份「永遠」聲明適用於哪些條件？

若作者明定 0 ≤ x_0 ≤ 1，而且每一步都有 0 ≤ u_t ≤ 1，就能提供一個完整而簡單的數學證明。初始狀態已在區間內。假設某一步 0 ≤ x_t ≤ 1，則 0 ≤ x_t + u_t ≤ 2，除以正數 2 後得到 0 ≤ x_(t+1) ≤ 1。以這個保持區間的步驟反覆套用，數學歸納法便保證每個 t 都符合結論。這是針對實數運算與明定輸入範圍的定理。

新增這段論證後，模擬並沒有變得多餘。模擬可以幫我們看不同輸入如何影響收斂快慢，也可以檢查實作是否出現不合預期的現象。只是「這些曲線沒有越界」與「所有合格序列都不越界」現在有不同的理由來源。若沒有把有限測試約化為一個真正窮盡的檢查，多跑一些曲線仍不會自動跨過兩種主張的距離；這個差別可對照[第十四章](ch14-computer-assisted-proofs.md)。

接著作者把這個模型用來描述一部實體裝置，爭議就改了。輸入感測器回報的 u_t 是否可靠？每一步真的依照這個更新式作用嗎？電腦使用的有限精度運算，是否保留數學式的性質？以上問題不由剛才的歸納法回答。那段證明仍然正確，只是它證成的條件句，還欠一段理由才能接上裝置。

可以用邊界值讓缺口更清楚。若某次實際輸入是 1.2，當 x_t = 1，公式給出的下一步就是 1.1，已超出區間。這沒有推翻附有 u_t ≤ 1 假設的定理，卻足以推翻「不管實際輸入如何，這部裝置都不越界」的擴大宣稱。面對這種反例，合理修補可能是限制適用範圍、修改控制規則，或增加能支持輸入界限的測量。再貼一張平穩圖不會回答同一個異議。

有時精確等式過於理想化，但可容許的誤差仍能說清楚。假設每一步多出誤差 e_t，且 ∣e_t∣ ≤ η，η 為一個固定非負數，則可改問較寬的區間能否保持。若 x_t 落在 −2η 與 1 + 2η 之間，並且 0 ≤ u_t ≤ 1，下一步 (x_t + u_t)／2 + e_t 的下界至少為 −2η，上界至多為 1 + 2η。因此只要初值也在這個區間，歸納理由仍然適用。誤差沒有遭到忽略，而是改變了可擔保的結論。

但 η 必須由另外的分析或測量支持，不能為了讓定理好看而任意挑小。這個例子顯示，接受一個應用中的證明，可以同時包含堅實的數學部分與尚待強化的經驗部分。把兩者統稱為「不確定」太粗；應當說，區間保持的推導已完成，而實際誤差是否滿足界限仍需檢查。這樣的剩餘問題才有下一步。

## 「永遠不為負」可能保護錯了東西

第三份文件把形式驗證放在封面。假想的庫存系統以非負整數 s 表示庫存、d 表示出貨量，更新成 s − d。AI 提出一個定理：更新後庫存永遠非負。若這裡採用 Lean 自然數的減法，差值低於零時會截成零；官方文件明定了這項語意。[^ch18-lean-nat]於是這個形式主張可以成立，卻可能沒有表達主管原先關心的事。

取 s = 3、d = 5，這種減法仍給出 0。畫面沒有負數，但模型容許嘗試出貨五件，而原庫存只有三件。如果原要求是「出貨不得超過可用庫存」，僅證明顯示值非負顯然不夠。這是本章構造的規格反例，並非宣稱某個真實產品發生過事故。反例要檢查的是自然語言需求與形式命題的關係，無須指控驗證器算錯。

要修補，得先把業務動詞變成能追蹤的數學關係。令 R 為累計入庫總量，W 為累計出貨總量，三個量 R、W、s 都是非負整數。希望保持 s + W = R，並且只允許 d ≤ s 的出貨。一次出貨後，令 s′ = s − d、W′ = W + d，R 不變。因為 d ≤ s，減去再加回 d 不會遭到截斷，於是 s′ + W′ = (s − d) + (W + d) = s + W = R。

入庫也要有對應步驟。若新增 r 件，r 為非負整數，就同時把 s 與 R 加上 r，W 不變，等式仍保持。從符合 s + W = R 的初始狀態出發，每次合法操作都保持等式，因此 W ≤ R。這才把「沒有超額出貨」連到一個能逐步檢查的理由。它仍是簡化模型：所有入庫與出貨都必須記錄，而且此處把一次更新當成不可分割的步驟。

若實作容許兩筆出貨同時讀到相同庫存，還需要證明並行處理符合這套操作語意。若實體貨物與資料紀錄不同步，也需另有核對方法。這些要求不是追求無窮無盡的完美，而是在辨認原宣稱會經過哪些接口。純數學的等式不會自動管住未列入模型的動作；改變模型後，也必須重查受影響的證明。

另一方面，要求驗證報告寫出依賴假設，並不表示任何假設都同樣可疑。採用既定形式基礎，與直接新增「本系統不會出錯」作為公理，不能混為一談。Lean 文件提供列出定理公理依賴的工具；這種紀錄能讓讀者看見結論依靠了哪些未在該系統中證出的前提。[^ch18-lean-axioms]詳細機制見[第十五章](ch15-proof-assistants.md)，此處的責任是讓依賴可見，而且與原始要求分開審查。

## 一份研究不能靠更響亮的「證明」補足設計

第四份文件聲稱，一門課提高了學生的推理能力。研究者展示上課者比未上課者成績高。這可能是一條值得追查的線索，但如果學生自行報名，原先的動機、程度或課外練習也可能影響結果。把分數重新計算十次，只能加強對同一計算的把握，不能憑空解決分組的原因。這項異議對準[第十三章](ch13-causality-and-replication.md)的因果識別問題。

研究者若改採隨機分派，還得明定要估計的效果。是獲得上課機會的平均效果，還是實際完整上完課的效果？若只保留最後出席的人，原先的分派比較就可能變質。這裡不需要把每一項方法都重講一遍；只需看出，研究問題中的「這門課有效」太寬，無法單靠一個漂亮差值獲得固定意義。

能處理異議的材料，包括分派方式、原定評量、退出與缺漏紀錄，以及從資料到結果的分析程序。若發現研究者只公開最有利的一種測量，問題在選擇結果；若相同資料算不出相同數字，問題在計算重現；若新一批學生沒有出現相同差異，則可能涉及隨機變動、情境差異或原效應判斷。不同疑點需要不同的補充工作。把所有爭議交給「是否達顯著」一個開關，會讓理由失去位置。

2019 年美國國家科學、工程與醫學院的報告，把科學理解為逐步精煉信心、容許修正的共同工作，也區分計算可重現與新資料結果的一致程度。[^ch18-nasem]這支持我們對研究報告採取不同於純數學反例的閱讀方式：一次新結果不一致，需要分析原因，未必能像 1681 = 41² 那樣直接否定一個清楚的全稱命題；但不一致也不能因為原報告已有聲望就被排除。

研究與定理因此各有嚴格之處。研究的誠實，在於讓設計、資料與不確定性接受適當檢查；定理的誠實，在於讓前提與推導完整支撐結論。要求研究提供脫離測量條件的演繹必然性，可能使人拒絕一切經驗知識。把研究中的「證據相當強」反過來套在有致命缺口的數學證明上，也不能讓缺口消失。選擇合適標準，本身就是一項責任。

## 誰都看得見，不表示誰都要重做

讀者可能提出一個實際反對：以上要求很好，但我們沒有時間檢查每份證明，也不可能同時懂幾何、程式、測量與統計。這個反對擊中了分工的必要，卻沒有取消責任定位的需要。正因為不可能事事自查，才更需要知道哪部分已有可信的檢查路徑，哪部分只有無法追查的保證。委託檢查是一種合理做法；委託對象與範圍仍應說清楚。

Thurston 在 1994 年的文章中，根據自己的數學經驗，討論專業社群如何以共同背景、交談、論文與解釋傳遞理解，也提醒形式記錄與實際思考之間並不完全重合。[^ch18-thurston]從這個觀察可以推出一項分工要求：專家不只應宣布結論，還應協助後來者找到進入理由的道路。專門語言讓合作有效率，但不能成為拒絕一切針對性提問的屏障。

一份證明可以分層交付。最外層說明精確命題與關鍵想法，中間層指出必要引理與依賴，最內層保存詳細推導或可執行的檢查材料。Lamport 提倡的階層式證明寫法，就把命名與結構用來呈現步驟及其理由，使讀者能選擇往下檢查的位置。[^ch18-lamport]分層不是把難處藏起來，而是讓難處有地址。

公開也要有可用性。只有一個龐大檔案，卻沒有定理入口、依賴版本或重做方法，形式上公開的材料仍可能很難檢查。只有生動解說而沒有足夠細節，則可能把信任全部綁在講述者身上。可讀的說明與可檢查的材料互相補足，服務不同程度的讀者。一個學生能指出量詞不對，一位專家能追查引理，一個驗證器能檢查形式步驟；每種介入都應有清楚的作用位置。

這也回答了「只要結果是真的，為什麼還要解釋」的疑問。解釋能讓人辨認適用範圍，預測修改條件的後果，並發現原本沒有想到的用途。前面的誤差區間從 0 到 1 擴成 −2η 到 1 + 2η，就需要理解保持區間的理由，才容易看出如何調整。只保存一個成功訊號，會失去這種可遷移的能力。要求解釋有知識上的用途，並非替已成立的定理另設作者資格。

## 什麼時候可以停止追問

還有一個更深的反對：若每項理由都要理由，檢查者也要檢查者，接受是不是永遠無法開始？實際上，接受總有範圍。對一個形式定理，可以明說採用哪些推理規則與背景公理，並確認推導符合它們；對一個實驗，可以交代設計與誤差支持到何種結論。停止點應當公開，而不是假裝沒有停止點。指出背景假設，不等於證明所有判斷都一樣好。

合理的停止也應對準尚存的具體疑點。若有人已給出可核查的算術反例，繼續調查作者的聲望沒有幫助；若爭議在感測器界限，反覆重證代數不會更接近答案。若手上的問題只是完整初等證明中一個清楚步驟，就不必為了形式化而啟動龐大工程。檢查資源有限，應用在可能改變結論的地方。這是一項關於證據作用的判斷，不是替草率找藉口。

行動也可能有期限。假設一個制度必須根據有限的證言與記錄分配責任，它可能訂出程序與接受門檻，並權衡誤判的後果。這裡只談有限資源下如何作決定，不引入法律上的證明門檻，也不把制度決策等同數學證明。接受某個行動方案，還涉及程序與價值判斷，不能只靠一個演繹符號回答。

反過來，行動上暫時接受某項結論，也不必聲稱所有疑點已經排除。假想的課程可以先試辦，持續收集與原問題相關的證據；模型可以只在已支持的輸入範圍內使用。這些選擇應說明決策根據與改變決策的條件，而不把「目前足以採取這一步」誇大成「永遠成立」。接受知識、接受風險與採取行動，可能相連，卻需要分別交代理由。

當檢查發現錯誤，最有生產力的回應是指出修改對象：撤回哪句話，補上哪個假設，重做哪段計算，哪些引用者需要知道。若新理由已處理特定異議，也應承認那項異議得到回答，不必無限移動要求。提出者不能靠名望豁免檢查，批評者也不能只靠持續懷疑占據優勢。雙方都應讓下一個可做的檢查更明確。

下次遇到「已證明」三個字，可以把空白留給四句實話：我主張的是哪一句；它在什麼條件下成立；你能沿著哪條路檢查；走完這條路後，還有哪一部分不能由此保證。若第三句只剩「大家都這樣說」，就去找那份缺少的理由；若第四句指出的限制會影響眼前用途，就補做相應工作。讓接受能回應具體異議，也讓修正有明確位置，證明才真正成為可以交給別人的東西。
